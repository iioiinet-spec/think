①좌표 놀이터 — 숫자 두 개로 자리를 정해요

운동장에서 친구를 찾을 때 "오른쪽으로 3걸음, 위로 2걸음" 이라고 말하면 정확히 찾을 수 있지요? 수학에서도 똑같이 합니다. 가로로 몇 칸, 세로로 몇 칸인지 숫자 두 개로 자리를 정하는 거예요.

( 가로 , 세로 ) = ( x , y )가로 x가 먼저, 세로 y가 나중! 순서를 바꾸면 다른 곳이 됩니다
  • x가 커지면 오른쪽으로, 작아지면(음수) 왼쪽으로 갑니다.
  • y가 커지면 위쪽으로, 작아지면(음수) 아래쪽으로 갑니다.
  • 가운데 (0, 0) 자리를 원점이라고 불러요. 모든 여행의 출발점입니다.

숫자 앞에 빼기(−)가 붙으면 반대 방향이에요.

②밀기 — 모양 그대로 자리만 옮기기

도형을 밀면 어떻게 될까요? 크기도 그대로, 모양도 그대로, 심지어 방향도 그대로입니다. 오직 자리만 바뀌어요. 종이에 그린 그림을 그대로 들어서 다른 곳에 내려놓는 것과 같습니다.

한 칸씩 밀기 한꺼번에 밀기

꼭짓점 좌표가 어떻게 변했나요?

네 꼭짓점 모두 똑같은 만큼 움직였나요? 표의 숫자를 비교해 보세요. 이것이 밀기의 가장 중요한 성질입니다.

( x , y )  →  ( x + ● , y + ▲ ) 오른쪽으로 ●칸, 위로 ▲칸 밀었다면 모든 점의 x에 ●를, y에 ▲를 더합니다

③뒤집기 — 거울에 비친 모습 (선대칭)

거울 앞에 서면 나와 똑같이 생긴 모습이 반대편에 보이지요. 도형도 거울선(대칭축)을 하나 정하고 뒤집으면 반대편에 똑같은 도형이 생깁니다. 이것을 선대칭이라고 해요.

  • 어떤 점이든 거울선까지의 거리가 똑같습니다. 3칸 떨어져 있었으면 반대편도 3칸!
  • 거울선 위에 있는 점은 뒤집어도 제자리입니다.
  • 모양과 크기는 그대로지만 왼쪽·오른쪽이 바뀝니다. 글자를 뒤집어 보면 금방 알 수 있어요.

조금 더! 거울선이 원점이 아니라 x = 3 같은 곳에 있으면 어떻게 될까요? 점에서 거울선까지 거리를 재서 반대편에 같은 거리로 놓으면 됩니다. 식으로 쓰면 ( 2×3 − x , y ) 예요. 위 실습판에서 k를 바꿔 가며 확인해 보세요.

④돌리기 — 압정을 꽂고 빙글 (회전)

종이 도형에 압정 하나를 꽂고 빙글 돌려 보세요. 압정을 꽂은 자리는 움직이지 않고, 나머지는 모두 그 자리를 중심으로 돕니다. 이 압정 자리를 회전의 중심이라고 해요.

  • 시계 방향은 시곗바늘이 도는 쪽, 반시계 방향은 그 반대입니다.
  • 90°는 직각만큼, 180°는 반 바퀴, 360°는 한 바퀴(제자리)예요.
  • 중심에서 각 꼭짓점까지의 거리는 변하지 않습니다.
회전의 중심

규칙을 찾아보세요! 원점을 중심으로 반시계 방향 90° 돌리면, 표에서 x자리와 y자리 숫자가 서로 바뀌고 하나에 빼기가 붙습니다. 몇 번 눌러 보면 규칙이 보일 거예요.

반시계 90°
( x , y ) → ( −y , x )
180°
( x , y ) → ( −x , −y )
시계 90°
( x , y ) → ( y , −x )

※ 위 식은 원점을 중심으로 돌릴 때예요. 중심이 다른 곳이면 중심에서 얼마나 떨어졌는지를 먼저 재야 합니다.

⑤점대칭 — 점 하나를 콕 찍고 반대편으로

점 하나를 정하고, 도형의 모든 꼭짓점을 그 점 너머 똑같은 거리에 옮겨 놓아 보세요. 이것이 점대칭입니다. 이때 찍은 점을 대칭의 중심이라고 해요.

비밀 하나: 점대칭은 사실 180°로 돌리기와 똑같습니다! ④번 탭에서 180° 버튼을 눌러 본 것과 비교해 보세요.

대칭의 중심을 움직여 보세요 가로 0 세로 0

확인해 보세요
연결선을 켜면 원래 점 — 중심 — 옮긴 점이 한 줄로 이어집니다. 그리고 중심은 두 점의 정확히 한가운데에 있어요. 이것이 점대칭의 핵심입니다.

중심이 ( p , q ) 일 때   ( x , y ) → ( 2p − x , 2q − y ) 중심이 원점 (0, 0)이면 그냥 ( −x , −y ) 가 됩니다

⑥이 도형은 어떤 대칭일까?

선대칭 도형
직선 하나를 그어 반으로 접었을 때 딱 포개지면 선대칭 도형입니다. 그 직선이 대칭축이에요. 대칭축은 하나일 수도, 여러 개일 수도 있습니다.

점대칭 도형
한 점을 중심으로 반 바퀴(180°) 돌렸을 때 똑같아 보이면 점대칭 도형입니다. 그 점이 대칭의 중심이에요.

아래 일곱 도형을 살펴보고 어떤 대칭인지 골라 보세요. 답을 고르면 대칭축(분홍 점선)이나 대칭의 중심(초록 점)이 나타납니다.

헷갈리기 쉬운 것

  • 평행사변형은 반으로 접어도 안 포개집니다. 하지만 반 바퀴 돌리면 똑같아요 → 점대칭만
  • 정삼각형·정오각형처럼 변이 홀수개인 정다각형은 선대칭이지만 점대칭은 아닙니다.
  • 바람개비는 돌리면 같지만 접으면 안 포개져요. 날개가 한쪽으로 휘어 있기 때문이에요.
