△ 이산기하 완전정복 — 정수 좌표로 푸는 계산기하

외적(CCW) 하나로 방향·넓이·교차·볼록껍질까지 전부 연결됩니다. 점을 직접 끌어보며 이론과 C 코드를 동시에 익힙니다.

1-1왜 "이산"기하인가 — 정수 좌표의 세계

고등학교 기하는 실수(√, sin, cos)를 씁니다. 하지만 정보올림피아드의 기하 문제는 좌표가 거의 항상 정수로 주어집니다. 그래서 우리는 실수를 최대한 피하고 정수만으로 답을 냅니다.

하고 싶은 것실수 방식 (위험)정수 방식 (안전)
두 점의 거리 비교sqrt(dx²+dy²)dx²+dy² (제곱 그대로 비교)
선분의 기울기 비교dy/dx (0으로 나눔 위험)외적으로 비교
삼각형 넓이밑변×높이/2|외적| / 2
각도 판정atan2, acos외적/내적 부호
실수는 왜 위험한가 — 0.1 + 0.2 != 0.3 입니다. 세 점이 정확히 일직선인지 판정할 때 실수를 쓰면 "거의 0"인 값이 0인지 아닌지 알 수 없어 오답이 납니다. 정수 연산은 오차가 0이므로 판정이 100% 정확합니다.

1-2벡터 — 점이 아니라 "화살표"로 생각하기

두 점 A(x₁,y₁), B(x₂,y₂)에 대해 A에서 B로 가는 벡터는 뺄셈으로 정의합니다.

AB→ = B − A = (x₂ − x₁,  y₂ − y₁)

이 "뺄셈으로 방향을 만든다"는 발상이 계산기하의 전부입니다. 앞으로 나올 모든 공식은 두 벡터를 만들고 → 외적을 구한다의 반복입니다.

거리는 제곱 상태로 다룬다

dist²(A,B) = (x₂−x₁)² + (y₂−y₁)²   // 루트를 씌우지 않는다

"어느 점이 더 가까운가?"를 묻는 문제에서 루트는 필요 없습니다. d₁ < d₂ ⟺ d₁² < d₂² 이기 때문입니다 (거리는 항상 0 이상).

Cbasic.c — 기본 구조체와 거리
typedef struct { long long x, y; } P;   // 좌표는 long long 권장

long long dist2(P a, P b) {           // 거리의 "제곱"
    long long dx = b.x - a.x;
    long long dy = b.y - a.y;
    return dx*dx + dy*dy;             // sqrt 없음 = 오차 없음
}
// dist2({1,2},{4,6}) = 9 + 16 = 25  (실제 거리 5)
오버플로 경보 — 좌표가 최대 109이면 dx·dx는 최대 약 4×1018. int(2.1×109)는 물론이고 long long(약 9.2×1018)도 아슬아슬합니다. 계산기하에서 int를 쓰는 것은 거의 항상 틀린 선택입니다.

2-1CCW — 계산기하의 심장

세 점 A, B, C가 주어졌을 때 "A→B로 갈 때 C는 왼쪽인가 오른쪽인가?"를 판정하는 것이 CCW(Counter-ClockWise)입니다. 답은 외적(cross product)의 부호입니다.

cross = (B−A) × (C−A) = (xB−xA)(yC−yA) − (yB−yA)(xC−xA)
cross 부호의미세 점의 배치
> 0반시계 방향 (CCW)C가 A→B의 왼쪽
< 0시계 방향 (CW)C가 A→B의 오른쪽
= 0방향 없음세 점이 한 직선 위 (공선)
외우는 법 — 시계 반대 방향이 양수. 수학 시간에 각도를 반시계로 재던 것과 같은 약속입니다. 부호만 기억하면 이후 모든 알고리즘이 따라옵니다.

2-2인터랙티브: CCW 판정기

▶ 점 A, B, C를 끌어서 부호가 어떻게 바뀌는지 확인하세요. C를 선분 AB의 연장선 위에 놓으면 0이 됩니다.

2-3C 코드 — 이 함수 하나가 시험의 절반

Cccw.c
typedef struct { long long x, y; } P;

// 외적 값 자체 (넓이 계산에 쓰임)
long long cross(P a, P b, P c) {
    return (b.x-a.x)*(c.y-a.y) - (b.y-a.y)*(c.x-a.x);
}

// 부호만 반환: 1(반시계) / -1(시계) / 0(일직선)
int ccw(P a, P b, P c) {
    long long v = cross(a, b, c);
    if (v > 0) return 1;
    if (v < 0) return -1;
    return 0;
}
절대 하지 말 것 — return v / abs(v); 같은 나눗셈(v=0이면 0으로 나눔), 그리고 int v = ... (오버플로). 위 형태를 그대로 외워서 쓰세요.

3-1삼각형 넓이 = |외적| / 2

외적의 절댓값은 두 벡터가 만드는 평행사변형의 넓이입니다. 삼각형은 그 절반입니다.

넓이(ABC) = |cross(A,B,C)| / 2

예: A(0,0), B(4,0), C(0,3) → cross = 4·3 − 0·0 = 12 → 넓이 = 6. 밑변 4 × 높이 3 ÷ 2 = 6 과 일치합니다.

정수로 답을 내는 요령 — 넓이는 항상 "정수 ÷ 2" 꼴이므로 소수점은 .0 아니면 .5 뿐입니다. 그래서 문제에서 "넓이의 2배를 출력하라"거나 "소수 첫째 자리까지 출력"이라고 하는 경우가 많습니다. 2배 값을 정수로 유지하다가 마지막에만 나누세요.

3-2신발끈 공식 — 다각형 넓이

꼭짓점이 P₁, P₂, ..., Pₙ 순서로 주어진 다각형의 넓이는 좌표를 신발끈처럼 엇갈려 곱해 구합니다.

넓이 = ½ | (x₁y₂ + x₂y₃ + ... + xny₁) − (y₁x₂ + y₂x₃ + ... + ynx₁) |

왜 성립할까? — 삼각형 분할

첫 꼭짓점 P₁을 기준으로 부채꼴처럼 삼각형을 쪼개고 외적을 전부 더하면 됩니다. 볼록하지 않은 다각형에서도 바깥으로 튀어나온 삼각형은 음수 외적이 되어 자동으로 상쇄됩니다. 이것이 신발끈 공식이 모든 단순다각형에서 통하는 이유입니다.

2 × 넓이 = | Σi=2n−1 cross(P₁, Pi, Pi+1) |   // 지난 시간의 시그마가 여기서 다시 등장

3-4픽의 정리(Pick's Theorem) — 진짜 "이산"기하

이산수학 ↔ 기하 연결 고리

꼭짓점이 모두 격자점(정수 좌표)인 다각형에서, 넓이는 격자점의 개수만 세면 나옵니다.

A = I + B/2 − 1
기호의미세는 법
A다각형의 넓이신발끈 공식
I내부 격자점 개수Interior
B경계 위 격자점 개수각 변마다 gcd(|dx|, |dy|) 를 더함

변 위의 격자점 개수가 최대공약수(gcd)로 나오는 것이 포인트입니다. 예를 들어 (0,0)→(4,6) 선분에는 gcd(4,6)=2 이므로 (끝점 하나 포함해서) 2개의 격자점이 놓입니다. 정수론과 기하가 만나는 지점입니다.

[격자점 세기 실행]을 눌러 픽의 정리를 확인하세요.
Cpick.c — 경계 격자점 세기
long long gcd(long long a, long long b) {
    return b ? gcd(b, a % b) : a;
}

long long B = 0;
for (int i = 0; i < n; i++) {

4-1선분 교차 판정 — CCW 네 번으로 끝내기

선분 AB와 CD가 만나는지 판정합니다. 핵심 아이디어: "C와 D가 직선 AB의 서로 반대편에 있고, 동시에 A와 B가 직선 CD의 서로 반대편에 있으면" 두 선분은 교차합니다.

ccw(A,B,C) × ccw(A,B,D) ≤ 0  그리고  ccw(C,D,A) × ccw(C,D,B) ≤ 0

부호가 다르면 곱이 음수 → 반대편에 있다는 뜻입니다. 등호(≤)를 넣으면 끝점이 닿는 경우, T자로 만나는 경우까지 포함됩니다.

단 하나의 예외 — 네 CCW 값이 모두 0인 경우(네 점이 한 직선 위)에는 위 조건이 항상 참이 되어버립니다. 이때는 겹치는지 떨어져 있는지를 좌표 범위로 따로 확인해야 합니다. 이 예외 처리를 빠뜨리는 것이 가장 흔한 감점 요인입니다.

4-3완성 코드 — 예외까지 포함한 표준형

Csegment_intersect.c
int onSeg(P a, P b, P p) {   // p가 a-b의 좌표 범위 안인가
    return MIN(a.x,b.x) <= p.x && p.x <= MAX(a.x,b.x)
        && MIN(a.y,b.y) <= p.y && p.y <= MAX(a.y,b.y);
}

int intersect(P a, P b, P c, P d) {
    int ab = ccw(a,b,c) * ccw(a,b,d);
    int cd = ccw(c,d,a) * ccw(c,d,b);

    if (ab == 0 && cd == 0) {      // 네 점이 한 직선 위
        return onSeg(a,b,c) || onSeg(a,b,d)
            || onSeg(c,d,a) || onSeg(c,d,b);
    }
    return ab <= 0 && cd <= 0;
}

이 함수는 KOI·BOJ의 "선분 교차" 계열 문제에서 그대로 복사해 쓸 수 있는 완성형입니다. 손으로 여러 번 써보며 익히세요.

5-1볼록 껍질(Convex Hull) — 점들을 감싸는 고무줄

평면에 점이 흩어져 있을 때, 전체를 감싸는 가장 작은 볼록 다각형이 볼록 껍질입니다. 못을 박고 고무줄을 튕겨 놓은 모양을 상상하세요.

KOI에서는 "울타리를 최소 길이로 치기", "가장 먼 두 점 찾기", "점들을 모두 포함하는 최소 볼록 도형" 같은 문제로 등장합니다.

모노톤 체인(Andrew's Monotone Chain) 알고리즘

① 점을 x좌표(같으면 y좌표) 기준으로 정렬
② 왼쪽→오른쪽으로 훑으며 아래 껍질 만들기
③ 오른쪽→왼쪽으로 훑으며 위 껍질 만들기
④ 붙이면 완성

핵심은 ②③의 규칙 하나입니다: 새 점을 넣기 전에, 스택의 마지막 두 점과 새 점이 "오른쪽으로 꺾이면"(ccw ≤ 0) 마지막 점을 버린다. 안쪽으로 파인 점은 이렇게 자동으로 제거됩니다.

5-3C 코드 — 모노톤 체인 완성형

Cconvex_hull.c — O(n log n)
int cmp(const void *A, const void *B) {   // x, 그다음 y 정렬
    const P *p = A, *q = B;
    if (p->x != q->x) return p->x < q->x ? -1 : 1;
    return p->y < q->y ? -1 : (p->y > q->y);
}

int convexHull(P *p, int n, P *st) {
    qsort(p, n, sizeof(P), cmp);
    int k = 0;

    // 아래 껍질
    for (int i = 0; i < n; i++) {
        while (k >= 2 && cross(st[k-2], st[k-1], p[i]) <= 0) k--;
        st[k++] = p[i];
    }
    // 위 껍질 (아래 껍질 크기를 하한으로 고정)
    int lower = k + 1;
    for (int i = n-2; i >= 0; i--) {
        while (k >= lower && cross(st[k-2], st[k-1], p[i]) <= 0) k--;
        st[k++] = p[i];
    }
    return k - 1;   // 시작점이 마지막에 중복되므로 -1
}
// 예제 8점 → 껍질 6개: (0,0)(5,0)(7,2)(6,4)(2,5)(1,3)
<= 인가 < 인가 — <= 0 으로 하면 일직선 위의 중간 점을 껍질에서 제외합니다(꼭짓점만 남김). < 0 으로 하면 포함합니다. 문제가 "꼭짓점의 개수"를 물으면 ≤, "껍질 위의 모든 점"을 물으면 <. 문제 조건을 반드시 확인하세요.
