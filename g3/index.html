▱ 넓이와 신발끈 공식 완전정복

삼각형 넓이에서 출발해 신발끈 공식의 유도, 오목 다각형에서도 통하는 이유, 그리고 정수만으로 답을 내는 C 구현까지.

1-1삼각형 넓이 — 밑변×높이를 버리는 이유

중학교에서 배운 공식은 밑변 × 높이 ÷ 2 입니다. 하지만 좌표평면 위의 임의의 삼각형에서 "높이"를 구하려면 수선의 발을 찾아야 하고, 그러려면 나눗셈과 루트가 필요합니다.

높이 = |ax + by + c| / √(a² + b²)   // 점과 직선 사이 거리 — 루트 등장!

반면 외적을 쓰면 덧셈·뺄셈·곱셈만으로 넓이의 2배가 정수로 나옵니다.

넓이(ABC) = |cross(A, B, C)| / 2
왜 2로 나누나 — 외적의 절댓값은 두 벡터가 만드는 평행사변형의 넓이입니다. 평행사변형을 대각선으로 자르면 합동인 삼각형 두 개가 되므로 절반이 삼각형 넓이입니다.

1-2인터랙티브: 두 공식 비교하기

▶ 세 점을 끌어 보세요. 밑변×높이 방식(실수 계산)과 외적 방식(정수 계산)이 같은 값을 내지만, 중간 과정이 얼마나 다른지 확인하세요.

관찰 — 밑변과 높이는 대부분 무리수(루트)가 되지만, 곱해서 반으로 나누면 신기하게도 정수 아니면 .5로 떨어집니다. 외적은 그 최종 결과를 중간 오차 없이 곧장 계산합니다.

절댓값을 벗기면 넓이에 부호가 생깁니다. 이것이 신발끈 공식이 작동하는 비밀입니다.

2-1신발끈 공식의 세 가지 얼굴 — 전부 같은 식

교재마다 다르게 생긴 식이 나와서 헷갈립니다. 하지만 셋 다 완전히 같은 값을 냅니다.

① 원점 기준형 (가장 많이 쓰임)
2A = | Σi=1n (xi·yi+1 − xi+1·yi) |   // Pn+1 = P1
② 부채꼴(삼각형 분할)형
2A = | Σi=2n−1 cross(P1, Pi, Pi+1) |
③ 사다리꼴형
2A = | Σi=1n (xi − xi+1)(yi + yi+1) |
어느 걸 외울까 — ①번을 외우세요. 코드가 가장 짧고, 원점을 따로 정할 필요가 없으며, 항이 대칭이라 실수가 적습니다. ②번은 "왜 성립하는가"를 이해할 때, ③번은 적분과 연결할 때 씁니다.

2-2왜 "신발끈"이라는 이름일까 — 계산 애니메이션

좌표를 세로로 나열하고 엇갈려 곱하면 그 모양이 운동화 끈을 묶은 것처럼 보입니다. 아래 [한 줄씩 계산]을 눌러 확인하세요.

[한 줄씩 계산]을 누르면 신발끈이 한 칸씩 엮입니다.
규칙 정리 — ↘ 방향(내려가며 오른쪽)으로 곱한 것은 더하고, ↙ 방향(내려가며 왼쪽)으로 곱한 것은 뺍니다. 마지막 줄에서 첫 좌표로 돌아와 끈을 묶어 마무리합니다.

2-3중요한 성질 ①: 원점이 어디든 상관없다

①번 식은 xiyi+1 − xi+1yi 로, 마치 원점 O를 기준으로 삼각형 O-Pi-Pi+1의 넓이를 더하는 것처럼 보입니다. 그런데 다각형이 원점에서 아무리 멀리 떨어져 있어도 답은 같습니다.

오각형 (0,0)(4,0)(5,3)(2,5)(0,3)을 평행이동해도 2A가 같은지 확인하세요.
이유 — 원점 바깥쪽에서 더해지는 삼각형과 빼지는 삼각형이 정확히 상쇄되기 때문입니다. 즉 신발끈 공식은 평행이동에 대해 불변(invariant)입니다. 좌표가 음수여도, 원점이 다각형 안이든 밖이든 그냥 쓰면 됩니다. 다만 개별 항은 좌표 크기에 비례해 커지므로 누적 변수는 반드시 long long이어야 합니다.

2-4중요한 성질 ②: 부호가 곧 꼭짓점의 방향

Σ 부호꼭짓점 순서활용
양수반시계(CCW)볼록껍질 결과는 보통 CCW
음수시계(CW)입력을 뒤집어 CCW로 정규화

넓이만 필요하면 절댓값을 씌우면 되지만, "다각형 내부 판정"이나 "볼록껍질"처럼 방향이 중요한 알고리즘에서는 먼저 CCW로 방향을 통일해 두는 것이 안전합니다. 4번 탭에 정규화 코드가 있습니다.

3-1가장 큰 의문: 오목 다각형에서도 왜 맞을까?

부채꼴 분할(②번 식)을 보면 이상합니다. P1에서 삼각형을 쪼개면 다각형 바깥으로 삐져나오는 삼각형이 생깁니다. 그런데도 답은 정확합니다.

비밀: 바깥으로 나간 삼각형은 시계 방향이 되어 음수 넓이가 되고,
안쪽에서 두 번 세어진 부분과 정확히 상쇄된다.

즉 신발끈 공식은 "잘 쪼개서 더하는" 것이 아니라 "더하고 빼는 회계"입니다. 이 관점이 잡히면 오목·별 모양 등 어떤 단순다각형에서도 안심하고 쓸 수 있습니다.

4-1구현 4단계 — 정수만으로 끝까지 간다

STEP 1. 넓이가 아니라 "넓이의 2배"를 구한다

넓이는 항상 정수 ÷ 2 꼴입니다. 그래서 2로 나누는 순간 실수가 되어 오차가 생깁니다. 2배 값을 정수로 끝까지 들고 갑니다.

Cshoelace.c
typedef struct { long long x, y; } P;

// 넓이의 2배 (부호 있음)
long long shoelace2(P *p, int n) {
    long long s = 0;
    for (int i = 0; i < n; i++) {
        P a = p[i], b = p[(i+1) % n];   // 마지막 → 첫 점 순환
        s += a.x*b.y - b.x*a.y;
    }
    return s;                        // 절댓값은 호출한 쪽에서
}
STEP 2. 소수 첫째 자리까지 출력하기

KOI·BOJ의 다각형 넓이 문제는 대부분 "소수점 아래 첫째 자리까지 출력"을 요구합니다. 2A가 짝수면 .0, 홀수면 .5입니다.

Cprint_area.c
void printArea(long long s2) {
    long long a = llabs(s2);
    printf("%lld.%lld\n", a/2, (a%2)*5);   // 홀수면 .5
}
// 2A=37 → "18.5"   2A=24 → "12.0"   2A=100 → "50.0"
%.1f 를 쓰면? — printf("%.1f", s2/2.0) 는 대부분 맞지만, 좌표가 크면 double 정밀도(약 15자리)를 넘어 마지막 자리가 틀립니다. 정수 나눗셈·나머지로 출력하는 위 방법이 100% 안전합니다.
STEP 3. 오버플로 점검
좌표 |x|, |y| ≤ 105, n ≤ 104 일 때
항 하나: 105 × 105 × 2 = 2×1010 → int(2.1×109) 초과!
전체 합: 2×1010 × 104 = 2×1014 → long long(9.2×1018) 안전

누적 변수 s는 반드시 long long. 항 하나만으로도 int를 넘기므로 int 배열에 좌표를 담았다면 곱하기 전에 캐스팅해야 합니다.

STEP 4. 방향 정규화 (필요할 때만)
Cnormalize.c
// 꼭짓점 순서를 항상 반시계(CCW)로 맞추기
void makeCCW(P *p, int n) {
    if (shoelace2(p, n) < 0) {          // 시계 방향이면
        for (int i = 0; i < n/2; i++) {   // 배열을 뒤집는다
            P t = p[i]; p[i] = p[n-1-i]; p[n-1-i] = t;
        }
    }
}

4-2완성 코드 — KOI 표준 제출 형태

Cpolygon_area.c — 입력: n, 이어서 n개의 좌표
#include <stdio.h>
#include <stdlib.h>

typedef struct { long long x, y; } P;
P p[10005];

int main(void) {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++)
        scanf("%lld %lld", &p[i].x, &p[i].y);   // %lld !

    long long s = 0;
    for (int i = 0; i < n; i++) {
        P a = p[i], b = p[(i+1) % n];
        s += a.x*b.y - b.x*a.y;
    }
    s = llabs(s);
    printf("%lld.%lld\n", s/2, (s%2)*5);
    return 0;
}
// 입력: 3 / 0 0 / 0 10 / 10 0   →  출력: 50.0

이 20줄이 다각형 넓이 문제의 완성형입니다. 시간복잡도 O(n), 오차 0.

4-3인터랙티브: 넓이 계산기 (출력 형식 확인)

꼭짓점을 끌어 모양을 바꾸면 2A와 실제 출력 문자열이 함께 갱신됩니다.

5-1응용 ①: 점이 다각형 내부인가 — 넓이 합으로 판정

아이디어가 예쁜 고전 기법

점 q를 볼록다각형의 모든 변과 이어 삼각형을 만듭니다. q가 내부에 있으면 이 삼각형들이 다각형을 빈틈없이 정확히 덮으므로 넓이 합 = 다각형 넓이. 밖에 있으면 삼각형들이 다각형 바깥까지 덮어 합이 더 커집니다.

[볼록다각형 전용]
Σi |cross(Pi, Pi+1, q)|  ==  |2A|  → 내부(또는 경계)
Σi |cross(Pi, Pi+1, q)|   >  |2A|  → 외부

▶ 노란 점 q를 끌어 안팎으로 옮겨 보세요. [오목 반례] 버튼을 누르면 이 방법이 깨지는 장면을 직접 볼 수 있습니다.

오목에서는 왜 깨지나 — 안으로 파인(reflex) 꼭짓점 근처에서는 q와 변을 이은 삼각형이 다각형 바깥으로 삐져나가 내부의 점인데도 합이 2A보다 커집니다. 예를 들어 오목 오각형 (1,1)(11,1)(11,8)(6,4)(1,8)에서 q=(3,3)은 분명 내부인데 합은 114, 2A는 100입니다.
정리 — 이 방법은 볼록다각형에서만 쓰세요. 코드가 짧은 대신 내부와 경계를 구분하지 못합니다(둘 다 등호). 오목까지 다뤄야 하면 광선 쏘기(ray casting)를, 경계 구분이 필요하면 CCW 부호 방식을 씁니다.

5-2응용 ②: 픽의 정리로 내부 격자점 세기

신발끈으로 구한 2A와 gcd로 구한 B만 있으면 내부 격자점 I를 O(n)에 정수로 구할 수 있습니다.

A = I + B/2 − 1   →   양변에 2를 곱하면    I = (2A − B + 2) / 2
Cpick_interior.c
long long gcd(long long a, long long b){ return b ? gcd(b, a%b) : a; }

long long A2 = llabs(shoelace2(p, n));      // 넓이의 2배
long long B = 0;
for (int i = 0; i < n; i++) {
    long long dx = llabs(p[(i+1)%n].x - p[i].x);
    long long dy = llabs(p[(i+1)%n].y - p[i].y);
    B += gcd(dx, dy);                       // 변마다 gcd 개
}
long long I = (A2 - B + 2) / 2;
// 오각형 (0,0)(4,0)(5,3)(2,5)(0,3): 2A=37, B=11 → I=14
다각형을 고르고 [격자점 세어 검증]을 눌러 공식과 실제 개수를 대조하세요.

5-3응용 ③: 최대 넓이 삼각형 찾기

점 n개 중 세 개를 골라 만드는 삼각형의 최대 넓이를 구합니다. n이 작으면(≤ 300 정도) 삼중 반복문으로 충분합니다.

Cmax_triangle.c — O(n³)
long long best = 0;
for (int i = 0; i < n; i++)
  for (int j = i+1; j < n; j++)
    for (int k = j+1; k < n; k++) {
        long long v = llabs(cross(p[i], p[j], p[k]));
        if (v > best) best = v;      // 2배 값끼리 비교 (나누지 않음!)
    }
printf("%lld.%lld\n", best/2, (best%2)*5);
핵심 요령 — 비교는 2배 값 그대로 합니다. 매번 2로 나누면 실수 연산이 n³번 들어가 느리고 부정확합니다. "나눗셈은 마지막 출력에서 딱 한 번"이 계산기하의 철칙입니다.
점 8개 중 최대 넓이 삼각형을 찾습니다. C₈,₃ = 56가지를 전부 확인합니다.

5-4응용 ④: 볼록 껍질의 넓이 · 둘레

"울타리를 쳐서 모든 점을 감싸라" 유형입니다. 볼록 껍질을 구한 뒤 신발끈이면 끝입니다.

① 볼록 껍질 구하기 O(n log n)  →  ② 껍질 꼭짓점에 신발끈 O(h)  →  넓이
둘레는 예외 — 둘레는 각 변의 실제 길이가 필요하므로 여기서만 sqrt를 씁니다. 넓이는 정수, 둘레는 실수 — 이 구분을 헷갈리지 마세요.
Chull_area.c
int h = convexHull(p, n, st);          // 껍질 꼭짓점 h개
long long A2 = llabs(shoelace2(st, h));  // 넓이 2배 (정수)

double peri = 0;                     // 둘레는 실수
for (int i = 0; i < h; i++) {
    double dx = st[(i+1)%h].x - st[i].x;
    double dy = st[(i+1)%h].y - st[i].y;
    peri += sqrt(dx*dx + dy*dy);
}

5-5응용 ⑤: 삼각형 분할로 다각형 넓이 검산하기

시험장에서 답이 의심스러울 때, 서로 다른 두 식으로 계산해 비교하면 실수를 잡을 수 있습니다.

Cverify.c — 두 방식 교차 검증
// 방법 1: 원점 기준형
long long s1 = 0;
for (int i = 0; i < n; i++)
    s1 += p[i].x*p[(i+1)%n].y - p[(i+1)%n].x*p[i].y;

// 방법 2: 부채꼴(삼각형 분할)형
long long s2 = 0;
for (int i = 1; i < n-1; i++)
    s2 += cross(p[0], p[i], p[i+1]);

// 반드시 s1 == s2 (부호까지 동일)
if (s1 != s2) printf("구현 오류!\n");
디버깅 팁 — 두 값이 다르면 대부분 인덱스 순환(%n)을 빠뜨렸거나, 마지막 꼭짓점에서 첫 꼭짓점으로 돌아오는 변을 계산하지 않은 것입니다.
