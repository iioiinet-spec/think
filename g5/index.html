⬡ 볼록 껍질 완전정복 — 점들을 감싸는 고무줄

고무줄 직관에서 출발해 모노톤 체인의 한 줄 규칙, 공선 처리, C 구현, 그리고 회전 캘리퍼스까지.

1-1정의 — 점들을 감싸는 가장 작은 볼록 도형

판에 못을 여러 개 박고 고무줄을 크게 벌려 놓았다가 놓으면, 고무줄은 바깥쪽 못들에 걸려 멈춥니다. 이때 고무줄이 이루는 다각형이 볼록 껍질(convex hull)입니다.

볼록 껍질 = 주어진 점들을 모두 포함하는 볼록 다각형 중 넓이가 가장 작은 것

"볼록"이란 다각형 안의 두 점을 이은 선분이 항상 다각형 안에 있는 성질입니다. 즉 안으로 파인 곳(오목한 곳)이 하나도 없습니다.

1-3왜 올림피아드에서 중요한가

문제 유형실제 문제 설명볼록 껍질로 푸는 이유
최소 울타리모든 나무를 감싸는 울타리의 최소 길이껍질의 둘레가 정답
가장 먼 두 점n개 점 중 거리가 최대인 쌍정답 쌍은 반드시 껍질 위에 있음
최소 포함 영역모든 점을 덮는 최소 볼록 영역의 넓이껍질에 신발끈 공식
점 포함 판정 반복쿼리마다 "이 점이 영역 안인가?"껍질로 만들면 O(log n) 판정 가능
가장 중요한 성질 — "가장 먼 두 점"의 정답은 항상 볼록 껍질의 꼭짓점 중에 있습니다. 내부 점을 아무리 골라도 바깥쪽 점보다 멀 수 없기 때문입니다. 그래서 n개 점 전부를 O(n²)로 비교하는 대신, 껍질 h개만 보면 됩니다. 5번 탭에서 이걸 O(h)까지 줄입니다.

2-1모노톤 체인 — 위아래로 나눠서 훑기

Andrew's Monotone Chain은 껍질을 아래쪽 절반과 위쪽 절반으로 나눠 각각 한 번씩 훑어 만듭니다.

① x좌표(같으면 y좌표) 기준으로 정렬
② 왼쪽 → 오른쪽으로 훑으며 아래 껍질 만들기
③ 오른쪽 → 왼쪽으로 훑으며 위 껍질 만들기
④ 두 껍질을 이어 붙이면 완성

단 하나의 규칙

while (스택 ≥ 2개 && cross(st[k−2], st[k−1], 새점) ≤ 0)  →  pop

스택의 마지막 두 점과 새 점이 오른쪽으로 꺾이면(시계 방향), 가운데 점은 껍질 안쪽으로 들어간 것이므로 버립니다. 왼쪽으로 꺾일 때까지 계속 버린 뒤 새 점을 넣습니다.

왜 정렬이 먼저인가 — x 순서로 훑으면 "되돌아가는" 일이 없어 각 점이 스택에 최대 한 번 들어가고 한 번 나옵니다. 그래서 훑는 과정 자체는 O(n)이고, 전체 시간은 정렬이 지배해 O(n log n)이 됩니다.

격자를 클릭해 점을 추가할 수 있습니다. [단계 실행]으로 push/pop이 일어나는 순간을 하나씩 확인하세요. 초록 = 스택에 있음, 노랑 = 지금 넣으려는 후보, 빨강 = 방금 버려진 점입니다.

[예제 점 배치] 후 [단계 실행]을 눌러 스택 변화를 관찰하세요.
관찰 포인트 — ① 아래 껍질을 만드는 동안 위쪽 점들은 스택에 잠깐 들어갔다가 전부 pop됩니다. ② 아래 껍질이 끝나면 그 크기를 하한선(lower)으로 고정해, 위 껍질을 만들 때 아래 껍질을 침범하지 않게 합니다. ③ 마지막에 시작점이 한 번 더 들어오므로 결과에서 하나를 뺍니다.

2-3왜 pop 한 번이면 충분한가 — 정당성

"오른쪽으로 꺾이는 점을 버린다"가 왜 정확히 껍질을 만들까요?

스택에 남은 점들은 항상 왼쪽으로만 꺾인다 → 볼록하다
버려진 점은 이전 점과 새 점을 잇는 선분의 오른쪽(안쪽)에 있다 → 껍질일 수 없다

즉 스택은 "지금까지 본 점들의 아래 껍질"이라는 성질(불변식)을 매 단계 유지합니다. 마지막 점까지 처리하면 그것이 곧 전체의 아래 껍질입니다.

시간복잡도 다시 보기 — while문이 안에 있어 O(n²)처럼 보이지만, 각 점은 평생 한 번만 pop될 수 있습니다. 전체 pop 횟수 ≤ n이므로 훑기는 O(n). 이런 분석을 분할상환 분석(amortized analysis)이라 합니다.

3-1구현 4단계

STEP 1. 정렬 비교 함수
Cstep1.c
typedef struct { long long x, y; } P;

int cmp(const void *A, const void *B) {
    const P *p = A, *q = B;
    if (p->x != q->x) return p->x < q->x ? -1 : 1;
    return p->y < q->y ? -1 : (p->y > q->y);
}
흔한 실수 — return p->x - q->x; 처럼 뺄셈으로 쓰면 long long 차이가 int 반환값으로 잘려 정렬이 깨집니다. 반드시 비교 후 −1/0/1을 직접 반환하세요.
STEP 2. 아래 껍질
Cstep2.c
int k = 0;
for (int i = 0; i < n; i++) {
    while (k >= 2 && cross(st[k-2], st[k-1], p[i]) <= 0) k--;
    st[k++] = p[i];
}
STEP 3. 위 껍질 — lower 하한선이 핵심
Cstep3.c
int lower = k + 1;          // 아래 껍질을 침범하지 못하게 고정
for (int i = n-2; i >= 0; i--) {   // 오른쪽 → 왼쪽
    while (k >= lower && cross(st[k-2], st[k-1], p[i]) <= 0) k--;
    st[k++] = p[i];
}
return k - 1;              // 시작점이 끝에 중복되므로 하나 빼기

lower를 k가 아니라 k+1로 두는 이유: 위 껍질이 아래 껍질의 마지막 점(가장 오른쪽 점)까지 지워버리면 안 되기 때문입니다. 여기를 k로 쓰면 특정 입력에서 껍질이 무너집니다.

STEP 4. 완성 코드
Cconvex_hull.c — 시험장 복사용 O(n log n)
#include <stdio.h>
#include <stdlib.h>

typedef struct { long long x, y; } P;
P p[100005], st[200005];

long long cross(P a, P b, P c) {
    return (b.x-a.x)*(c.y-a.y) - (b.y-a.y)*(c.x-a.x);
}
int cmp(const void *A, const void *B) {
    const P *a = A, *b = B;
    if (a->x != b->x) return a->x < b->x ? -1 : 1;
    return a->y < b->y ? -1 : (a->y > b->y);
}
int convexHull(int n) {
    qsort(p, n, sizeof(P), cmp);
    if (n < 3) {                     // 예외: 점이 2개 이하
        for (int i = 0; i < n; i++) st[i] = p[i];
        return n;
    }
    int k = 0;
    for (int i = 0; i < n; i++) {                  // 아래 껍질
        while (k >= 2 && cross(st[k-2], st[k-1], p[i]) <= 0) k--;
        st[k++] = p[i];
    }
    int lower = k + 1;
    for (int i = n-2; i >= 0; i--) {              // 위 껍질
        while (k >= lower && cross(st[k-2], st[k-1], p[i]) <= 0) k--;
        st[k++] = p[i];
    }
    return k - 1;
}
int main(void) {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++)
        scanf("%lld %lld", &p[i].x, &p[i].y);
    printf("%d\n", convexHull(n));
    return 0;
}

배열 st는 2n 크기로 잡습니다. 아래 껍질과 위 껍질이 이어 붙으면서 최대 n+1개까지 쌓일 수 있기 때문입니다.

3-2≤ 인가 < 인가 — 공선 점 처리

부등호 하나로 결과가 완전히 달라집니다. 아래는 한 변에 점이 여러 개 놓인 상황입니다.

부등호결과이럴 때 쓴다
cross <= 0 → pop꼭짓점만 남김 (공선 점 제거)"껍질의 꼭짓점 개수는?" / 넓이 계산
cross < 0 → pop변 위의 점도 모두 포함"껍질 위에 있는 점의 개수는?"

4-2인터랙티브: 선물 포장 애니메이션

가장 왼쪽 아래 점에서 출발해, 나머지 모든 점 중 "가장 시계 반대쪽"에 있는 점을 하나씩 고릅니다. 종이를 포장지로 감싸는 모습과 비슷해 이런 이름이 붙었습니다.

[포장 시작]을 눌러 보세요. 한 꼭짓점을 찾을 때마다 n개 점을 전부 확인합니다.
Cgift_wrapping.c — O(n·h)
int start = 0;
for (int i = 1; i < n; i++)          // 가장 왼쪽(같으면 아래) 점
    if (p[i].x < p[start].x ||
       (p[i].x == p[start].x && p[i].y < p[start].y)) start = i;

int cur = start, h = 0;
do {
    st[h++] = p[cur];
    int nxt = (cur + 1) % n;
    for (int i = 0; i < n; i++) {
        long long c = cross(p[cur], p[nxt], p[i]);
        // i가 더 바깥(왼쪽)이거나, 일직선이면 더 먼 점 선택
        if (c > 0 || (c == 0 && dist2(p[cur],p[i]) > dist2(p[cur],p[nxt])))
            nxt = i;
    }
    cur = nxt;
} while (cur != start);
언제 쓸까 — 껍질 꼭짓점 h가 매우 작다고 보장될 때(예: h ≤ 10)는 선물 포장이 더 빠를 수 있습니다. 하지만 모든 점이 원 위에 있으면 h = n이 되어 O(n²)로 터집니다. 일반적인 문제에서는 모노톤 체인을 쓰세요.

5-1응용 ①: 껍질의 넓이와 둘레 — 최소 울타리

껍질을 구했으면 그 다음은 지난 시간의 신발끈 공식입니다. 다만 넓이는 정수, 둘레는 실수라는 점을 구분해야 합니다.

넓이 — 정수 그대로
2A = |Σ (xiyi+1 − xi+1yi)|
출력만 a/2 . (a%2)*5
둘레 — 여기서만 sqrt
L = Σ √((Δx)² + (Δy)²)
실수 누적 오차 주의
격자를 클릭해 점을 추가하거나 예제를 불러온 뒤 계산해 보세요.

5-2응용 ②: 가장 먼 두 점 — 회전하는 캘리퍼스

껍질을 구한 뒤의 대표 기법

n개 점 중 가장 먼 쌍(지름)을 찾습니다. 전부 비교하면 O(n²)이지만, 정답은 반드시 껍질 위에 있고, 껍질을 한 바퀴 돌며 마주 보는 점만 따라가면 O(h)에 끝납니다.

캘리퍼스(자)를 껍질 양쪽에 대고 돌리면, 마주 보는 점 쌍만 단조롭게 움직인다
→ i를 한 칸 옮길 때 j는 되돌아가지 않는다 → 전체 O(h)
[캘리퍼스 회전]을 눌러 마주 보는 점이 따라 도는 모습을 확인하세요.
Crotating_calipers.c — O(h)
long long dist2(P a, P b) {
    long long dx = a.x-b.x, dy = a.y-b.y;
    return dx*dx + dy*dy;          // 제곱 그대로! sqrt 금지
}

int h = convexHull(n);
long long best = 0;
int j = 1;
for (int i = 0; i < h; i++) {
    while (dist2(st[i], st[(j+1)%h]) > dist2(st[i], st[j]))
        j = (j+1) % h;            // j는 되돌아가지 않는다
    long long d = dist2(st[i], st[j]);
    if (d > best) best = d;
}
// best는 거리의 제곱. 거리가 필요하면 마지막에 sqrt 한 번
제곱 거리로 비교하는 이유 — 거리 비교는 제곱 비교와 결과가 같습니다(둘 다 0 이상). sqrt를 n번 호출하면 느리고 오차도 생깁니다. "거리의 제곱을 정수로 비교하고, 필요하면 마지막에 한 번만 sqrt"가 원칙입니다.

5-3응용 ③: 점 포함 판정을 O(log n)으로

껍질을 한 번 구해 두면, "이 점이 영역 안인가?" 쿼리를 이진 탐색으로 O(log n)에 답할 수 있습니다. 쿼리가 수십만 번 들어오는 문제에서 필수입니다.

① 껍질을 반시계 순으로 정렬하고 P0를 기준점으로 삼는다
② q가 부채꼴 P0PiPi+1 중 어디에 속하는지 이진 탐색으로 찾는다
③ 그 삼각형 안에 있는지 ccw로 확인한다
방법전처리쿼리 1회적용 대상
모든 변에 ccw없음O(n)볼록 다각형
광선 쏘기없음O(n)오목 포함 모든 단순다각형
부채꼴 이진 탐색O(n log n)O(log n)볼록 다각형, 쿼리 다수

5-4응용 ④: 두 껍질을 합치기 (민코프스키 감각)

"두 무리의 점을 모두 감싸는 최소 볼록 영역"은 두 점 집합을 합쳐 껍질을 한 번 더 구하면 됩니다. 두 껍질의 꼭짓점만 모아도 결과는 같습니다.

hull(A ∪ B) = hull( hull(A) ∪ hull(B) )

이 성질 덕분에 내부 점을 미리 버려도 안전합니다. 데이터가 클 때 부분마다 껍질을 구해 합치는 분할정복이 가능해집니다.

실전 요령 — 점이 매우 많은데 껍질만 필요하다면, 먼저 x, y가 최대·최소인 4점이 만드는 사각형 내부의 점들을 통째로 버리는 전처리를 넣으면 정렬량이 크게 줄어듭니다.
