행렬(Matrix)

행렬은 단순 계산 도구가 아니라 그래프, 관계, 경로, 상태 전이, 점화식, 빠른 거듭제곱을 하나의 형식으로 표현하는 강력한 이산수학 도구입니다.

1. 행렬은 무엇인가?

행렬은 숫자를 직사각형 표 형태로 배열한 것입니다. 이산수학에서는 “여러 상태 사이의 관계”를 한 번에 표현하는 데 매우 자주 사용합니다.

기본 형태

A = [aᵢⱼ],   i=행(row), j=열(column)
123456

위 행렬은 2행 3열, 즉 2×3 행렬입니다.

정보올림피아드에서의 의미

행과 열에 정점, 상태, 시간, 변수 등을 배치하면 복잡한 구조를 하나의 표로 표현할 수 있습니다.

그래프 DP 점화식 경로

핵심 관점: 행렬은 “수를 담는 표”가 아니라 변환과 관계를 표현하는 언어입니다.

영행렬모든 원소가 0O

예제: A가 3×4 행렬이라면 원소 a₂₃은 2번째 행, 3번째 열의 값입니다.

4. 가장 중요한 행렬 곱셈

행렬 곱셈은 같은 위치끼리 곱하는 것이 아닙니다. 앞 행렬의 한 행(row)과 뒤 행렬의 한 열(column)을 짝지어 곱한 뒤 모두 더합니다.

C = AB,   cᵢⱼ = Σₖ aᵢₖbₖⱼ
곱셈 가능 조건: A가 m×n, B가 n×p라면 AB는 m×p입니다. 즉 앞 행렬의 열 개수 = 뒤 행렬의 행 개수여야 합니다.

5. 항등행렬과 전치행렬

항등행렬 I

숫자의 1과 같은 역할을 합니다.

AI = IA = A
100010001

전치행렬 Aᵀ

행과 열을 서로 바꿉니다.

(Aᵀ)ᵢⱼ = Aⱼᵢ

그래프에서 무방향 그래프의 인접행렬은 대칭행렬이 됩니다.

6. 그래프를 행렬로 표현하기: 인접행렬

정점 i에서 j로 간선이 있으면 1, 없으면 0을 기록합니다.

인접행렬 A

그래프는 A→B, A→C, B→C, C→D, D→A로 구성됩니다.

장점: 두 정점 사이에 간선이 있는지 O(1)에 확인할 수 있습니다. 단점: 정점이 많고 간선이 적은 희소 그래프에서는 메모리를 많이 사용합니다.

7. 행렬의 거듭제곱과 경로 개수

그래프의 인접행렬 A에 대해 A²의 (i,j) 원소는 i에서 j로 길이 2인 경로의 개수를 뜻합니다.

(A²)ᵢⱼ = Σₖ AᵢₖAₖⱼ

왜냐하면 i→k와 k→j가 모두 존재하는 중간 정점 k의 개수를 세기 때문입니다.

확장: Aᵏ의 (i,j) 원소는 i에서 j로 정확히 k개의 간선을 사용해 이동하는 경로의 개수입니다.

8. 이산수학의 관계(Relation)와 행렬

집합 X={1,2,3} 위의 관계 R을 0과 1로 표현할 수 있습니다.

R={(1,1),(1,2),(2,3),(3,1)}라면
MR = [[1,1,0], [0,0,1], [1,0,0]]
반사적

모든 i에 대해 (i,i)∈R → 대각선이 모두 1

대칭적

(i,j)∈R이면 (j,i)∈R → 행렬이 대칭

추이적

i→j, j→k이면 i→k도 존재

연결: 관계의 성질을 그래프와 행렬로 동시에 해석할 수 있다는 점이 이산수학의 중요한 통합 관점입니다.

9. 점화식을 행렬로 바꾸기

행렬은 점화식을 빠르게 계산하는 데 매우 중요합니다. 대표적으로 피보나치 수열이 있습니다.

Fₙ₊₁ = Fₙ + Fₙ₋₁

[ Fₙ₊₁ ] = [1 1] [ Fₙ ]
[ Fₙ ] [1 0] [ Fₙ₋₁ ]

따라서

[ Fₙ₊₁ ] = [1 1]ⁿ [F₁]
[ Fₙ ] [1 0] [F₀]
의미: O(n) 반복 대신 행렬 빠른 거듭제곱을 사용하면 O(log n)에 Fₙ을 구할 수 있습니다.

10. 행렬 빠른 거듭제곱

거듭제곱을 n번 곱하지 않고, 지수를 절반씩 줄이면 O(log n)에 계산할 수 있습니다.

A⁸ = ((A²)²)²
A¹³ = A⁸·A⁴·A 
Matrix power(Matrix A, long long n){
    Matrix R = identity();
    while(n > 0){
        if(n % 2 == 1) R = R * A;
        A = A * A;
        n /= 2;
    }
    return R;
}
시간복잡도

k×k 행렬의 일반 곱셈은 O(k³), 거듭제곱은 O(k³ log n)

출제 연결

큰 n의 점화식, 경로 개수, 상태 전이, 문자열 패턴, DP 최적화

11. 정보올림피아드에서 자주 나오는 연결 예제

예제 1. 그래프 경로
인접행렬 A에서 (A³)₂₄=5라면, 정점 2에서 4까지 정확히 3개의 간선을 사용하는 경로가 5개 있다는 뜻입니다.
예제 2. 상태 전이
상태가 3개이고 한 단계 후 가능한 이동을 행렬 T로 표현하면, 초기 상태 벡터 v에 대해 k단계 후 상태는 Tᵏv로 계산할 수 있습니다.
예제 3. 피보나치
F₁₀=55. 반복문은 10번 가까이 계산하지만 행렬 거듭제곱은 지수를 절반씩 줄여 계산합니다.
예제 4. 관계
무방향 그래프의 인접행렬은 Aᵀ=A이므로 대칭행렬입니다.
예제 5. 행렬 곱
A가 2×3, B가 3×4이면 AB는 2×4. 반대로 BA는 3×3이 아니라 애초에 곱셈이 불가능합니다(4와 2가 맞지 않음).
예제 6. 모듈러 행렬
경로 개수가 매우 커지면 각 행렬 곱셈마다 mod 1,000,000,007을 적용해 오버플로와 큰 수를 관리합니다.
