개념 2×2 단계별 예제 직접 입력 2×2 3×3 예제 해의 개수 알고리즘 확인문제

1. 가우스 소거법이란?

여러 개의 연립방정식을 행렬로 바꾼 뒤, 아래쪽 계수를 차례로 0으로 만들어 계산하기 쉬운 형태로 바꾸는 방법입니다.

1단계

연립방정식을 확대행렬로 바꾼다.

2단계

피벗 아래의 숫자를 0으로 만든다.

3단계

아래 행부터 위로 대입해 해를 구한다.

x + y = 5
2x + 3y = 12
↓
[ 1 1 | 5 ]
[ 2 3 |12 ]
핵심 아이디어: 첫 번째 식을 이용해서 두 번째 식의 x를 없애면, 두 번째 식에는 y만 남습니다. 그러면 y를 먼저 구하고 다시 x를 구할 수 있습니다.

2. 꼭 알아야 할 세 가지 행 연산

행 바꾸기
R₁ ↔ R₂

두 식의 순서를 바꿉니다.

행에 상수 곱하기
R₁ ← kR₁

한 식의 양변에 같은 수를 곱하는 것과 같습니다.

다른 행의 배수 더하기
R₂ ← R₂ - 2R₁

한 식에서 다른 식의 배수를 빼는 것과 같습니다.

왜 해가 안 바뀔까? 식의 순서를 바꾸거나, 양변에 같은 수를 곱하거나, 한 식의 배수를 다른 식에 더하거나 빼도 원래 연립방정식을 만족하는 해는 그대로이기 때문입니다.

4. 내가 직접 연립방정식을 입력해서 풀어보기

아래 확대행렬은

a₁₁x + a₁₂y = b₁
a₂₁x + a₂₂y = b₂

계수를 바꾸고 버튼을 누르면, 소거 계수부터 뒤에서 대입하는 과정까지 자동으로 설명합니다.

5. 3×3 가우스 소거법은 어떻게 확장될까?

3개의 미지수에서는 같은 과정을 한 번 더 반복합니다.

x + y + z = 6
2x + 3y + z = 11
x - y + 2z = 5
[1 1 1 | 6]
[2 3 1 |11]
[1 -1 2 | 5]

① 첫 번째 피벗으로 x 제거

R₂ ← R₂ - 2R₁
R₃ ← R₃ - R₁
[1 1 1 | 6]
[0 1 -1 |-1]
[0 -2 1 |-1]

② 두 번째 피벗으로 y 제거

R₃ ← R₃ + 2R₂
[1 1 1 | 6]
[0 1 -1 |-1]
[0 0 -1 |-3]

③ 뒤에서부터 대입

-z=-3 → z=3
y-z=-1 → y=2
x+y+z=6 → x=1
최종 해: x=1, y=2, z=3

6. 가우스 소거 결과로 해의 개수를 판별하기

유일해
[1 0 |3]
[0 1 |2]

모든 변수에 피벗이 존재합니다.

해 없음
[1 1 |2]
[0 0 |1]

두 번째 행은 0=1이라는 모순입니다.

무수히 많은 해
[1 1 |2]
[0 0 |0]

한 식이 다른 식과 겹쳐 자유변수가 생깁니다.

7. 알고리즘에서는 어떻게 구현할까?

핵심은 각 열에서 피벗을 정하고, 아래 행의 같은 열을 0으로 만드는 것입니다.

for (int col = 0, row = 0; col < n && row < n; col++) {

    // 1. 피벗 행 찾기
    int pivot = row;
    for (int i = row; i < n; i++)
        if (abs(a[i][col]) > abs(a[pivot][col]))
            pivot = i;

    // 2. 피벗이 0이면 이 열은 건너뜀
    if (abs(a[pivot][col]) < EPS) continue;

    swap(a[pivot], a[row]);

    // 3. 아래쪽 원소를 0으로 만들기
    for (int i = row + 1; i < n; i++) {
        double factor = a[i][col] / a[row][col];

        for (int j = col; j <= n; j++)
            a[i][j] -= factor * a[row][j];
    }

    row++;
}
시간복잡도

일반적으로 O(n³)

핵심 자료구조

n×(n+1) 확대행렬

실수 계산 주의: 컴퓨터에서는 소수 오차가 있기 때문에 `값 == 0` 대신 `abs(값) < EPS`처럼 비교합니다. 또한 큰 피벗을 선택하면 수치적으로 더 안정적입니다.

8. 한눈에 보는 가우스 소거법 사고 순서

① 피벗

현재 열에서 기준이 될 숫자를 정한다.

② 제거

피벗 아래 원소를 0으로 만든다.

③ 반복

오른쪽 아래 부분행렬에서 같은 작업을 반복한다.

④ 계단형

삼각형 모양의 행 사다리꼴을 만든다.

⑤ 역대입

가장 아래 변수부터 값을 구한다.

⑥ 판별

모순 행이나 자유변수가 있는지도 확인한다.
