1. 역행렬이란?

숫자에서 5의 역수는 1/5이고, 5×(1/5)=1입니다. 행렬에서도 이와 비슷하게 어떤 행렬 A를 곱했을 때 항등행렬 I가 되는 행렬을 생각할 수 있습니다.

AA⁻¹ = A⁻¹A = I

숫자

5 × 1/5 = 1

행렬

A × A⁻¹ = I

중요: 모든 행렬에 역행렬이 존재하는 것은 아닙니다. 정사각행렬 중에서도 행렬식(det)이 0이 아닌 경우에만 역행렬이 존재합니다.

2. 2×2 행렬의 역행렬 공식

A가 다음과 같다고 합시다.

A = [ a b ]
    [ c d ]

행렬식은 다음과 같습니다.

det(A) = ad - bc

det(A) ≠ 0이면 역행렬은

A⁻¹ = 1/(ad-bc) · [ d -b ]
　　　　　　　　　[ -c a ]

3. 기본 행 연산(Elementary Row Operations)

가우스 소거법은 행렬의 행을 바꾸면서도 연립방정식의 해를 유지하는 세 가지 연산만 사용합니다.

① 행 교환

R₁ ↔ R₂

두 행의 위치를 바꿉니다.

② 상수배

R₁ ← kR₁ (k≠0)

한 행 전체에 0이 아닌 수를 곱합니다.

③ 다른 행의 배수 더하기

R₂ ← R₂ + kR₁

한 행에 다른 행의 배수를 더합니다.

왜 가능한가? 연립방정식에서 식의 순서를 바꾸거나, 양변에 같은 수를 곱하거나, 한 식의 배수를 다른 식에 더해도 해는 변하지 않기 때문입니다.

4. 가우스 소거법(Gaussian Elimination)

가우스 소거법은 행렬을 행 사다리꼴(Row Echelon Form)로 만들어 아래쪽 원소를 0으로 제거한 뒤, 뒤에서부터 대입하여 해를 구합니다.

연립방정식
x + y = 5
2x + 3y = 12
[1 1 | 5]
[2 3 |12]

R₂ ← R₂ - 2R₁

[1 1 |5]
[0 1 |2]

둘째 식에서 y=2, 첫째 식에 대입하면 x=3.

핵심 전략: 왼쪽 위에서 시작해 피벗(pivot)을 잡고, 그 아래 원소들을 0으로 만들어 삼각형 모양으로 정리합니다.

5. 가우스-조르당 소거법(Gauss-Jordan Elimination)

가우스 소거법보다 한 단계 더 진행하여 피벗의 위와 아래를 모두 0으로 만듭니다. 최종적으로 왼쪽 부분을 항등행렬 I로 만듭니다.

[1 1 |5] → [1 0 |3]
[0 1 |2] → [0 1 |2]

그러면 해를 바로 읽을 수 있습니다.

x=3, y=2
연결: 역행렬을 가우스-조르당 소거법으로 구할 때는 [A | I]를 [I | A⁻¹]로 변환합니다.

6. 확대행렬(Augmented Matrix)

연립방정식의 계수와 우변 상수를 하나의 행렬로 합친 것을 확대행렬이라고 합니다.

2x + y = 5
x - y = 1
계수행렬 A = [2 1]　상수벡터 b=[5]
　　　　　　[1 -1]　　　　　　[1]

이를 확대행렬로 쓰면

[A | b] = [2 1 | 5]
　　　　 [1 -1 | 1]
의미: 미지수 x,y의 계수와 등호 오른쪽 숫자를 한 표 안에 넣어 행 연산으로 동시에 처리할 수 있습니다.

9. 역행렬로 연립방정식 풀기

연립방정식을 행렬식으로 표현하면

Ax = b

양변 왼쪽에 A⁻¹을 곱하면

A⁻¹Ax = A⁻¹b → Ix = A⁻¹b → x = A⁻¹b
2x+y=5, x-y=1
A=[[2,1],[1,-1]], b=[[5],[1]]
A⁻¹을 구한 뒤 A⁻¹b를 계산하면 x=2, y=1.
주의: 실제 알고리즘에서는 연립방정식을 풀기 위해 역행렬을 직접 계산하는 것보다 가우스 소거법을 사용하는 경우가 더 일반적입니다. 계산량과 수치 오차 측면에서 더 적절하기 때문입니다.

10. [A | I]로 역행렬 구하기

2×2 또는 더 큰 행렬의 역행렬도 가우스-조르당 소거법으로 구할 수 있습니다.

[A | I] → 행 연산 → [I | A⁻¹]
A = [[2,1],[1,1]]이면

[2 1 | 1 0]
[1 1 | 0 1]

R₁↔R₂
[1 1 | 0 1]
[2 1 | 1 0]

R₂←R₂-2R₁
[1 1 | 0 1]
[0 -1 | 1 -2]

R₂←-R₂, R₁←R₁-R₂
[1 0 | 1 -1]
[0 1 |-1 2]

따라서 A⁻¹=[[1,-1],[-1,2]].

11. 알고리즘 관점에서 보는 가우스 소거법

n개의 미지수를 갖는 n원 연립방정식은 n×(n+1) 확대행렬로 표현할 수 있습니다.

for (int col=0, row=0; col<n && row<n; col++) {
    // 1. pivot 선택
    int sel = row;
    for (int i=row; i<n; i++)
        if (abs(a[i][col]) > abs(a[sel][col]))
            sel = i;

    // 2. pivot이 0이면 다음 열
    if (abs(a[sel][col]) < EPS) continue;

    swap(a[sel], a[row]);

    // 3. 아래 행 제거
    for (int i=row+1; i<n; i++) {
        double factor = a[i][col] / a[row][col];
        for (int j=col; j<=n; j++)
            a[i][j] -= factor * a[row][j];
    }
    row++;
}
시간복잡도

일반적인 가우스 소거법은 O(n³)

정보올림피아드 연결

선형 방정식, XOR 방정식, GF(2), 확률 DP, 회로/그래프 모델링 등에 응용됩니다.

심화: 비트 연산 문제에서는 실수 대신 0/1만 사용하는 GF(2) 위의 가우스 소거법을 사용하기도 합니다. 이때 덧셈과 뺄셈은 XOR과 같은 역할을 합니다.

예제 2. A=[[2,4],[1,2]]의 역행렬 존재 여부
det=4-4=0 → 역행렬 없음.
예제 3. x+y=7, x-y=1
두 식을 더하면 2x=8 → x=4, y=3. 가우스 소거로도 같은 결과.
예제 4. x+y=2, 2x+2y=4
둘째 행에서 첫째 행의 2배를 빼면 [0 0 | 0] → 무수히 많은 해.
예제 5. x+y=2, 2x+2y=5
둘째 행에서 첫째 행의 2배를 빼면 [0 0 | 1] → 0=1 모순 → 해 없음.
