1. 자연수와 정수, 무엇이 다른가?

정보올림피아드에서는 단순히 “양수/음수”를 구분하는 것보다, 어떤 연산을 했을 때 결과가 어느 집합 안에 남는지 이해하는 것이 중요합니다.

자연수 ℕ

보통 0, 1, 2, 3, … 또는 1, 2, 3, …으로 정의합니다. 문제마다 0 포함 여부를 확인해야 합니다.

ℕ = {0, 1, 2, 3, ...}

정수 ℤ

자연수에 음수를 포함한 집합입니다.

ℤ = {..., -3, -2, -1, 0, 1, 2, 3, ...}

수직선으로 이해하기

2
올림피아드 핵심: 정수는 순서가 있고, 절댓값과 부호를 가지며, 덧셈·뺄셈·곱셈에 대해 닫혀 있습니다.

2. 정수 연산의 성질과 닫힘성

교환법칙
a+b=b+a
a×b=b×a
결합법칙
(a+b)+c=a+(b+c)
분배법칙
a(b+c)=ab+ac

닫힘성

연산자연수정수주의
덧셈닫힘닫힘항상 같은 집합 안
뺄셈보장 안 됨닫힘3-5=-2
곱셈닫힘닫힘항상 정수
나눗셈보장 안 됨보장 안 됨1/2는 정수가 아님
예제: 정수 a,b에 대해 a-b가 항상 정수인 이유는? → 정수는 덧셈과 음수에 대해 닫혀 있으므로 a+(-b)도 정수입니다.

3. 약수와 배수

a가 b의 약수라는 것은 어떤 정수 k가 존재하여 b = ak가 되는 것입니다. 기호로는 a | b라고 씁니다.

a | b ⇔ ∃k ∈ ℤ, b = ak

중요 성질

a|b, a|c 이면 a|(b+c), a|(b-c)

a|b 이면 모든 정수 m에 대해 a|mb

예제

6|24, 6|42 이므로 6|(42-24)=18

따라서 “공통 약수”는 차이에도 그대로 적용됩니다.

약수 탐색 실습

60의 약수를 찾아보세요.
알고리즘 연결: n의 약수를 1부터 n까지 모두 확인하면 O(n)이지만, √n까지만 확인하면 O(√n)으로 줄일 수 있습니다.

4. 소수와 합성수

소수(prime)는 1보다 큰 자연수 중 양의 약수가 1과 자기 자신뿐인 수입니다. 1은 소수가 아닙니다.

소수 예

2, 3, 5, 7, 11, 13, 17, 19, …

합성수 예

4=2×2, 6=2×3, 12=2²×3

왜 √n까지만 보면 될까?

n=ab일 때 a,b가 모두 √n보다 클 수는 없습니다. 둘 다 √n보다 크면 ab>n이 되기 때문입니다. 따라서 합성수라면 적어도 하나의 약수는 √n 이하에 존재합니다.

5. 최대공약수(GCD)와 최소공배수(LCM)

GCD

두 정수의 공통 약수 중 가장 큰 양의 정수

gcd(24,18)=6

LCM

두 양의 정수의 공통 배수 중 가장 작은 양의 정수

lcm(24,18)=72
a×b = gcd(a,b) × lcm(a,b)   (a,b>0)

유클리드 호제법

핵심 성질은 gcd(a,b)=gcd(b,a mod b)입니다.

int gcd(int a, int b){
    while(b != 0){
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}

6. 나눗셈 정리와 몫·나머지

정수 a와 양의 정수 m에 대해, a는 항상 다음처럼 유일하게 표현됩니다.

a = qm + r,   0 ≤ r < m
예: 23 = 4×5 + 3 → 몫 4, 나머지 3

나머지가 중요한 이유

시간, 요일, 순환 배열, 원형 큐, 반복 패턴처럼 “주기”가 있는 문제는 나머지로 모델링할 수 있습니다.

7. 합동식(modular arithmetic)

두 정수 a,b를 m으로 나눈 나머지가 같으면 mod m에서 합동이라고 합니다.

a ≡ b (mod m) ⇔ m | (a-b)
17 ≡ 5 (mod 12), 왜냐하면 17-5=12이고 12|12이기 때문입니다.

연산 성질

(a+b) mod m = ((a mod m)+(b mod m)) mod m
(a-b) mod m = ((a mod m)-(b mod m)) mod m
(ab) mod m = ((a mod m)(b mod m)) mod m
주의: C/C++에서 음수 % 양수의 결과는 음수가 될 수 있습니다. 항상 0 이상 나머지가 필요하면 ((x % m) + m) % m을 사용합니다.

8. 짝수·홀수, 패리티와 불변량

정수를 2로 나눈 나머지는 0 또는 1뿐입니다. 이것이 패리티(parity)입니다.

연산결과
짝수 + 짝수짝수
짝수 + 홀수홀수
홀수 + 홀수짝수
홀수 × 홀수홀수
불변량 예제: 한 번의 연산으로 두 수에 각각 1을 더한다고 하자. 두 수의 합은 매번 2씩 증가하므로 합의 홀짝은 변하지 않습니다. 따라서 시작 합이 홀수라면 어떤 과정을 거쳐도 짝수가 될 수 없습니다.
올림피아드 관점: “계속 변하는 것” 대신 “절대로 변하지 않는 것”을 찾는 것이 불변량 문제의 핵심입니다.

9. 진법과 정수 표현

정수는 자릿값의 합으로 표현됩니다. 10진수뿐 아니라 2진수, 8진수, 16진수도 같은 원리입니다.

(101101)₂ = 1·2⁵ + 0·2⁴ + 1·2³ + 1·2² + 0·2 + 1 = 45

2진수

컴퓨터 내부 표현의 기본. 비트 연산과 직접 연결됩니다.

비트 관점

11. 대표 예제 6문제

예제 1. 84의 양의 약수 개수는?
풀이: 84=2²×3×7. 약수는 각 소인수의 지수를 0~해당 지수까지 선택하므로 (2+1)(1+1)(1+1)=12개.
예제 2. 2¹⁰⁰을 7로 나눈 나머지는?
풀이: 2³=8≡1 (mod 7), 100=3×33+1 → 2¹⁰⁰≡2.
예제 3. 252와 105의 최대공약수는?
풀이: 252=105×2+42, 105=42×2+21, 42=21×2 → gcd=21.
예제 4. 연속한 두 정수의 곱은 항상 짝수임을 보여라.
풀이: 연속한 두 정수 중 하나는 반드시 짝수이므로 곱에 인수 2가 포함됩니다.
예제 5. n을 3으로 나눈 나머지가 2라면 n²의 나머지는?
풀이: n≡2 (mod 3), n²≡4≡1 (mod 3).
예제 6. 1부터 100까지에서 3 또는 5의 배수 개수는?
풀이: 포함배제: ⌊100/3⌋+⌊100/5⌋-⌊100/15⌋=33+20-6=47.
