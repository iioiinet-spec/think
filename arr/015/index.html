4. 3×3에서는 어떻게 확장될까?

x+y+z=6
2x+3y+z=11
x-y+2z=5
[1 1 1 | 6]
[2 3 1 |11]
[1 -1 2 | 5]

① 첫 열의 아래를 0으로

R₂←R₂-2R₁, R₃←R₃-R₁
[1 1 1 | 6]
[0 1 -1 |-1]
[0 -2 1 |-1]

② 둘째 열의 아래를 0으로

R₃←R₃+2R₂
[1 1 1 |6]
[0 1 -1|-1]
[0 0 -1|-3]

③ 셋째 피벗을 1로

R₃←-R₃
[1 1 1 |6]
[0 1 -1|-1]
[0 0 1 |3]

④ 셋째 열의 위를 0으로

R₁←R₁-R₃, R₂←R₂+R₃
[1 1 0 |3]
[0 1 0 |2]
[0 0 1 |3]

⑤ 둘째 열의 위를 0으로

R₁←R₁-R₂
[1 0 0 |1]
[0 1 0 |2]
[0 0 1 |3]
최종 해: x=1, y=2, z=3

5. 왜 역행렬과 연결될까?

가우스-조르당 소거법은 역행렬을 구할 때도 그대로 사용됩니다.

[A | I] → [I | A⁻¹]
A = [[2,1],[1,1]]
[2 1 |1 0]
[1 1 |0 1]

행 연산을 반복해 왼쪽을 I로 만들면

[1 0 | 1 -1]
[0 1 |-1 2]

따라서

A⁻¹ = [[1,-1],[-1,2]]
연결 포인트: 연립방정식에서는 [A|b]를 [I|x]로 만들고, 역행렬에서는 [A|I]를 [I|A⁻¹]로 만듭니다.

6. 알고리즘 관점의 가우스-조르당

for (int col = 0; col < n; col++) {
    // 1. pivot 선택
    int pivot = col;
    for (int r = col; r < n; r++)
        if (abs(a[r][col]) > abs(a[pivot][col]))
            pivot = r;

    swap(a[pivot], a[col]);

    // 2. pivot을 1로
    double div = a[col][col];
    for (int j = 0; j <= n; j++)
        a[col][j] /= div;

    // 3. pivot 열의 위·아래를 모두 0으로
    for (int r = 0; r < n; r++) {
        if (r == col) continue;

        double factor = a[r][col];

        for (int j = 0; j <= n; j++)
            a[r][j] -= factor * a[col][j];
    }
}
시간복잡도

일반적으로 O(n³)

최종 형태

RREF(Reduced Row Echelon Form), 즉 기약 행 사다리꼴

7. 기억해야 할 4단계

① 피벗 선택

기준 원소를 정합니다.

② 피벗을 1로

그 행 전체를 피벗 값으로 나눕니다.

③ 위·아래를 0으로

다른 모든 행에서 피벗 열을 제거합니다.

④ 다음 열 반복

오른쪽 아래로 이동하며 반복합니다.

⑤ 항등행렬 완성

왼쪽이 I가 됩니다.

⑥ 결과 읽기

오른쪽 열에서 해를 바로 읽습니다.
