좌표평면 위의 직선

두 점을 찍으면 직선이 그려지고, 기울기 · 절편 · 점까지의 거리 · 두 직선의 교점까지 계산 과정이 그대로 나옵니다

기울기x절편 · y절편 점과 직선 사이의 거리연립방정식

준비 — 좌표평면, 기울기, 절편

좌표평면 위의 점은 (x, y) 두 수로 정해집니다. 그런데 점 두 개가 주어지면 놀랍게도 그 둘을 지나는 직선은 단 하나뿐입니다. 그래서 "두 점 → 직선의 방정식"을 구할 수 있는 것이지요.

직선을 나타내는 방법은 여러 가지입니다. 이 자료에서는 두 가지를 함께 씁니다.

y = a x + b기울기 a, y절편 b — 세로선(x = k)은 표현 못 함
p x + q y = r일반형 — 세로선도 가로선도 모두 표현 가능

기울기 — "오른쪽으로 갈 때 얼마나 올라가나"

두 점 A(x₁, y₁), B(x₂, y₂)를 지나는 직선의 기울기는 세로로 변한 양을 가로로 변한 양으로 나눈 값입니다.

기울기  a = ( y₂ − y₁ ) ÷ ( x₂ − x₁ ) = Δy / Δx 어느 점을 먼저 잡아도 결과는 같습니다 (분자·분모 부호가 함께 바뀌므로)
기울기 a 1 y절편 b 0 y = x

슬라이더를 움직이며 확인하세요

  • a > 0 이면 오른쪽 위로 올라가는 직선
  • a < 0 이면 오른쪽 아래로 내려가는 직선
  • a = 0 이면 가로로 눕는 직선 (y = b)
  • |a|가 클수록 더 가파릅니다
  • b는 직선이 y축을 지나는 자리 (0, b)

그림의 계단이 기울기를 보여 줍니다. 오른쪽으로 1칸 갈 때 세로로 a칸 움직이지요.

절편 — 축과 만나는 자리

y절편 : 직선이 y축과 만나는 점의 y좌표. x = 0을 대입해서 구합니다.

x절편 : 직선이 x축과 만나는 점의 x좌표. y = 0을 대입해서 구합니다.

예) y = 2x − 6 에서  y절편은 x=0을 넣어 −6,  x절편은 y=0을 넣어 0 = 2x − 6 → x = 3 입니다.

점과 직선 사이의 거리

"거리"란 무엇을 말할까요? 점 P에서 직선 위의 여러 점까지 선을 그어 보면 길이가 제각각입니다. 그중 가장 짧은 것을 점과 직선 사이의 거리라고 약속합니다. 그리고 가장 짧은 선은 항상 직선과 수직입니다.

직선과 수직으로 만나는 그 점을 수선의 발 H라고 부르고, 거리는 선분 PH의 길이입니다. 실습판에서 초록 점선이 바로 이 선분이에요.

방법 1 · 수선의 발을 찾아 피타고라스 정리 (원리)

  • 직선에 수직인 방향을 찾아 점 P에서 직선까지 선을 내립니다 → 수선의 발 H(x_H, y_H)
  • 두 점 사이의 거리 공식으로 계산합니다.
PH = √{ ( x_P − x_H )² + ( y_P − y_H )² } 실습판에서 이 값과 아래 공식 값이 정확히 같은지 비교해 보세요

방법 2 · 공식으로 한 번에 (심화)

직선을 일반형 px + qy = r 로 써 두면, 점 (x₀, y₀) 까지의 거리는 다음 한 줄로 나옵니다.

d = | p·x₀ + q·y₀ − r | ÷ √( p² + q² ) 분자에 절댓값이 붙는 이유: 점이 직선의 어느 쪽에 있든 거리는 양수여야 하니까요
  • 분자는 점의 좌표를 방정식에 넣었을 때 얼마나 안 맞는지를 나타냅니다. 점이 직선 위에 있으면 정확히 0이 되고, 그래서 거리도 0이 됩니다.
  • 분모 √(p² + q²) 는 방정식을 몇 배로 쓰든 답이 같아지도록 크기를 맞춰 주는 역할을 합니다. 예를 들어 2x + 2y = 4 와 x + y = 2 는 같은 직선이니 거리도 같아야 하지요.

참고 — 이 공식은 고등학교에서 정식으로 배웁니다. 중학교 과정에서는 수선의 발을 찾아 계산하는 방법 1을 이해하는 것이 목표이고, 공식은 답을 빠르게 확인하는 도구로 쓰세요.

손으로 따라 해 보기

문제 — 두 점 A(1, 2), B(5, 4)를 지나는 직선과 점 P(4, 7) 사이의 거리를 구하시오.

① 기울기 : a = (4 − 2) ÷ (5 − 1) = 2/4 = 1/2 ② 방정식 : y − 2 = (1/2)(x − 1) → y = (1/2)x + 3/2 ③ 일반형 : 양변에 2를 곱하면 2y = x + 3 → x − 2y = −3 (p=1, q=−2, r=−3) ④ 대입 : p·4 + q·7 − r = 1×4 + (−2)×7 − (−3) = 4 − 14 + 3 = −7 ⑤ 거리 : d = |−7| ÷ √(1² + (−2)²) = 7 ÷ √5 = 7√5 / 5 ≒ 3.13

실습판 탭에서 A(1,2), B(5,4), P(4,7)을 찍어 같은 답이 나오는지 확인해 보세요.

두 직선의 교점 — 연립방정식으로 증명하기

교점의 정체 — 교점은 두 직선 위에 동시에 있는 점입니다. 즉 그 점의 좌표를 두 방정식에 모두 넣었을 때 둘 다 성립해야 합니다. 그래서 교점을 구하는 일은 두 방정식을 동시에 만족하는 (x, y)를 찾는 일, 곧 연립방정식을 푸는 일과 완전히 같습니다.

두 직선의 위치 관계 세 가지

위치 관계기울기와 y절편연립방정식의 해교점
한 점에서 만남기울기가 다르다해가 하나교점 1개
평행기울기 같음, y절편 다름해가 없다교점 없음
일치기울기 같음, y절편 같음해가 무수히 많다모든 점이 교점

푸는 방법 두 가지

방법 A · 대입법 (y = ax + b 꼴일 때 편리)

① y = 2x − 1 ② y = −x + 5 y가 같으므로 우변끼리 같다고 놓는다 2x − 1 = −x + 5 3x = 6 → x = 2 ①에 대입 : y = 2×2 − 1 = 3 교점 (2, 3)

방법 B · 가감법 (일반형 px + qy = r 일 때 편리)

① 2x − y = 1 ② x + y = 5 두 식을 더하면 y가 사라진다 (2x + x) + (−y + y) = 1 + 5 3x = 6 → x = 2 ②에 대입 : 2 + y = 5 → y = 3 교점 (2, 3)

반드시 해야 할 마지막 단계 — 검산

구한 좌표를 두 방정식 모두에 넣어 좌변과 우변이 같은지 확인합니다. 하나만 맞고 다른 하나가 틀리면 그 점은 교점이 아닙니다. 실습판의 교점 카드에서도 검산 과정을 함께 보여 줍니다.

① 에 (2, 3) 대입 : 2×2 − 3 = 4 − 3 = 1 ✓ 우변과 같다 ② 에 (2, 3) 대입 : 2 + 3 = 5 ✓ 우변과 같다 → 따라서 (2, 3)은 확실히 두 직선의 교점이다

왜 "기울기가 다르면 반드시 한 점에서 만날까?"

일반형 p₁x + q₁y = r₁, p₂x + q₂y = r₂ 를 가감법으로 풀면 x의 계수가 p₁q₂ − p₂q₁ 이 됩니다. 이 값이 0이 아니면 x가 딱 하나로 정해지고, 따라서 y도 하나로 정해집니다. 그런데 이 값이 0이라는 것은 두 직선의 기울기가 같다는 뜻이에요. 그래서 기울기가 다르다 = 반드시 한 점에서 만난다가 됩니다.

자주 하는 실수

  • 기울기를 구할 때 분자와 분모를 뒤집는 실수 — 세로가 분자입니다. (Δy가 위)
  • x축과 평행한 직선의 기울기는 0, y축과 평행한 직선은 기울기를 정할 수 없습니다 (분모가 0). 이때는 x = k 로 씁니다.
  • x절편을 구할 때 y에 0을 넣어야 하는데 x에 0을 넣는 실수가 잦습니다.
  • 교점을 구한 뒤 검산을 생략하면 계산 실수를 못 잡습니다.
