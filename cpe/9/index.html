정렬·탐색 필수예제 30

O(n²) 정렬의 성질부터 병합·퀵·힙·계수·기수 정렬, 이분 탐색과 lower_bound, 매개변수 탐색, 투 포인터·슬라이딩 윈도우·좌표 압축·그리디까지 KOI/정올 진입에 필요한 30가지를 다룹니다. 각 문제는 동작 과정과 연산 횟수를 함께 출력해, 복잡도를 이론이 아니라 숫자로 체감하도록 구성했습니다. 모든 코드는 gcc와 파이썬에서 직접 실행해 출력이 완전히 일치함을 확인했습니다.

정렬·탐색 알고리즘 요약

알고리즘평균 / 최악특징 · 쓰는 상황
버블O(n²) / O(n²)안정. 조기 종료 시 최선 O(n)
선택O(n²) / O(n²)불안정. 교환 최소(최대 n−1회)
삽입O(n²) / O(n²)안정. 거의 정렬된 데이터에 최선 O(n)
병합O(n log n) / O(n log n)안정. 항상 일정, 추가 메모리 O(n)
퀵O(n log n) / O(n²)불안정. 제자리, 실전 최속 / 피벗 주의
힙O(n log n) / O(n log n)불안정. 최악도 보장, 추가 메모리 없음
계수O(n + K)정수 + 좁은 값 범위일 때만
기수O(d(n + K))자릿수가 적은 큰 데이터
이분 탐색O(log n)정렬 전제. lower/upper_bound로 확장
투 포인터O(n)정렬·양수 등 단조성이 있을 때

시간 감각: 1초 ≈ 1억 연산. n이 1,000이면 O(n²)도 가능하지만 n이 100,000이면 반드시 O(n log n) 이하여야 합니다. 문제를 읽으면 n의 크기부터 확인하고 알고리즘을 고르세요. 오답의 대부분은 이분 탐색 경계 조건(< vs <=, mid 포함 여부), 정렬 안정성 오해, 투 포인터의 전제 조건 무시에서 나옵니다.
