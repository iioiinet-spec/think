벡터란 — 크기와 방향을 함께 가진 양

몸무게 60kg, 온도 25℃ 처럼 숫자 하나로 끝나는 양을 스칼라라고 합니다. 그런데 "시속 30km로 북동쪽으로"처럼 방향까지 있어야 뜻이 통하는 양이 있습니다. 이것이 벡터입니다.

좌표평면에서는 원점 O에서 점 (x, y)로 향하는 화살표로 그리고, 그 점의 좌표를 그대로 벡터의 성분이라고 부릅니다.

a = ( ax , ay )화살표의 "가로로 얼마, 세로로 얼마"가 곧 성분입니다

벡터가 가진 세 가지 정보

세 가지를 식으로

성분   a = (aₓ, a_y) = (5, 3) 크기   |a| = √(aₓ² + a_y²) = √34 ≒ 5.831 방향각 θ = atan2(a_y, aₓ) ≒ 30.96° 단위벡터 â = a / |a| ≒ (0.857, 0.514)
  • 크기는 피타고라스 정리 그대로입니다. 화살표의 길이예요.
  • 방향각은 x축 양의 방향에서 반시계로 잰 각입니다.
  • 단위벡터는 크기를 1로 줄인 것. 방향만 남긴 벡터라서 코딩에서 아주 많이 씁니다.

왜 atan2 를 쓸까? — 코딩에서 꼭 알아야 할 것

각도를 구할 때 arctan(y/x)를 쓰면 두 가지 문제가 생깁니다. 첫째, x = 0이면 나눗셈이 안 됩니다. 둘째, (3, 4)와 (−3, −4)는 y/x 값이 같아서 정반대 방향인데도 같은 각이 나옵니다. atan2(y, x)는 x와 y의 부호를 각각 보기 때문에 네 사분면을 모두 구별하고 x = 0도 처리합니다. 그래서 거의 모든 언어가 이 함수를 따로 제공합니다.

합과 차 — 성분끼리 더하고 빼면 끝


  

    
a + b = ( aₓ + bₓ , a_y + b_y )　　　a − b = ( aₓ − bₓ , a_y − b_y )
      x는 x끼리, y는 y끼리. 이것이 벡터 덧셈이 코드로 옮기기 쉬운 이유입니다

  


  

    

      
삼각형법 — 이어 붙이기

      
a의 화살표 끝에서 b를 다시 그리면, 원점에서 마지막 끝점까지가 a + b입니다. "동쪽으로 3, 그다음 북쪽으로 4를 갔더니 결국 어디?"라는 뜻이에요.

      
순서를 바꿔도 같습니다. b를 먼저 가고 a를 가도 도착점은 같아요. 이것이 교환법칙 a + b = b + a 이고, 실습판에서 평행사변형이 보이는 이유입니다.

    

    

      
평행사변형법 — 두 변으로 둘러싸기

      
a와 b를 두 변으로 하는 평행사변형을 그리면 대각선이 곧 a + b입니다. 힘 두 개가 동시에 작용할 때 실제로 물체가 움직이는 방향이 이 대각선입니다.

      
그리고 나머지 대각선(b의 끝에서 a의 끝으로 가는 화살표)이 바로 a − b 입니다. 실습판에서 차를 눌러 확인해 보세요.

    

  


  

    
차를 이해하는 가장 좋은 방법

    
a − b = a + ( −b )−b 는 b와 크기는 같고 방향만 정반대인 벡터

    
게임 코드에서 가장 많이 쓰는 형태 — 적의 위치 enemy에서 내 위치 me를 빼면 enemy − me 는 나에게서 적을 향하는 방향 벡터가 됩니다. 여기에 단위벡터를 씌우고 속도를 곱하면 추적 AI가 완성되지요. 뺄셈의 순서를 바꾸면 반대 방향이 되니 주의하세요.

  


  

    
스칼라배 — 방향은 그대로, 길이만 조절

    
k · a = ( k·aₓ , k·a_y )

    
    
      
  • k > 1 : 같은 방향으로 길어짐  ·  0 < k < 1 : 같은 방향으로 짧아짐
    • 
      
  • k < 0 : 방향이 정반대로 뒤집힘  ·  k = 0 : 영벡터 (0, 0)
    • 
      
  • |k·a| = |k| × |a| — 크기는 |k|배가 됩니다
    • 
    

  







  
곱 — 벡터의 곱셈은 두 종류다


  

    
수의 곱셈은 하나뿐이지만, 벡터의 곱셈은 결과가 무엇이냐에 따라 두 가지로 나뉩니다. 이름과 결과를 헷갈리지 않는 것이 가장 중요합니다.

    

      
이름기호와 식결과무엇을 알려주나

      
내적
dot product		
          a · b = aₓbₓ + a_yb_y스칼라 (수)
          두 벡터가 얼마나 같은 방향을 보는가. 각도 계산과 수직 판정에 씁니다.

      
외적
cross product		
          a × b = aₓb_y − a_ybₓ수 (2D)
3D에서는 벡터		
          두 벡터가 만드는 평행사변형의 넓이와 회전 방향(왼쪽/오른쪽)을 알려줍니다.

    

  


  

    

      
내적의 핵심 — 방향이 얼마나 닮았나

      
a · b = |a| |b| cos θ

      
    
        
  • a · b > 0 : 사잇각이 예각 — 대체로 같은 쪽을 봄
    • 
        
  • a · b = 0 : 사잇각이 직각 — 두 벡터가 수직!
    • 
        
  • a · b < 0 : 사잇각이 둔각 — 대체로 반대쪽을 봄
    • 
      

      
수직 판정이 이렇게 쉬워집니다. 기울기를 구해 −1인지 볼 필요 없이 dot(a,b) === 0 한 줄이면 됩니다. 세로선처럼 기울기를 정할 수 없는 경우도 문제없어요.

      
사잇각 구하기 — 위 식을 뒤집으면 θ = acos( (a·b) / (|a||b|) ) 입니다. 실습판의 내적 메뉴에서 계산 과정을 볼 수 있습니다.

    

    

      
외적의 핵심 — 넓이와 회전 방향

      
a × b = |a| |b| sin θ

      
    
        
  • |a × b| = a, b가 만드는 평행사변형의 넓이
    • 
        
  • 그 절반은 삼각형의 넓이 — 좌표로 삼각형 넓이를 구할 때 그대로 씁니다
    • 
        
  • a × b > 0 : b가 a의 왼쪽(반시계)  ·  < 0 : 오른쪽(시계)
    • 
        
  • a × b = 0 : 두 벡터가 평행 (넓이가 0)
    • 
      

      
이것이 CCW입니다. 알고리즘에서 점 세 개의 방향을 판정하는 CCW 함수가 바로 이 외적이에요. 볼록 껍질, 선분 교차 판정, 다각형 넓이(신발끈 공식)가 전부 여기서 나옵니다.

    

  


  

    
주의 — 성분끼리 곱하는 것은 벡터의 곱이 아닙니다

    
(aₓ·bₓ, a_y·b_y) 처럼 성분끼리 곱한 것은 수학의 벡터 곱이 아니라 프로그래밍에서 쓰는 요소별 곱(element-wise)입니다. NumPy에서 a * b를 쓰면 이 요소별 곱이 나오므로, 내적을 원한다면 반드시 np.dot(a, b) 또는 a @ b 를 써야 합니다. 실습에서 가장 흔한 실수예요.

실전에서 이렇게 쓰입니다

  

    
① 추적 / 이동

      
목표까지의 방향 벡터를 구해 단위벡터로 만들고 속도를 곱해 더합니다.

      
dir = normalize(target − pos)
pos = pos + dir * speed * dt

    
② 반사 (튕기기)

      
벽의 법선 n을 알면 내적 하나로 반사 벡터가 나옵니다.

      
r = v − 2 * dot(v, n) * n
// n은 반드시 단위벡터

    
③ 시야 판정

      
내가 보는 방향과 적 방향의 내적으로 "앞에 있는가"를 판정합니다.

      
if dot(forward, toEnemy) > 0:
    # 앞쪽에 있다

    
④ 삼각형 넓이

      
두 변 벡터의 외적 절댓값의 절반입니다.

      
area = abs(cross(B−A, C−A)) / 2

    
⑤ 좌우 판정 (CCW)

      
외적의 부호만 보면 됩니다. 볼록 껍질 알고리즘의 핵심.

      
s = cross(B−A, C−A)
s > 0 → 반시계, s < 0 → 시계

    
⑥ 회전

      
각도만큼 돌리는 것도 성분 계산 두 줄입니다.

      
x' = x·cosθ − y·sinθ
y' = x·sinθ + y·cosθ

  


  

    
NumPy 사용 시 꼭 알아둘 두 가지

    
    
      
  • a * b 는 내적이 아닙니다. 성분끼리 곱하는 요소별 곱이에요. 내적은 np.dot(a, b) 또는 a @ b.
    • 
      
  • np.cross 로 2차원 벡터의 외적을 구하는 방식은 NumPy 2.0부터 사용이 권장되지 않습니다(deprecated). 2D에서는 a[0]*b[1] - a[1]*b[0] 로 직접 계산하는 것이 안전합니다.
    •

구하는 것식결과의 종류 · 쓰임

    
성분a = (aₓ, a_y)벡터 — 배열 [x, y]

    
크기|a| = √(aₓ² + a_y²)스칼라 — 거리, 속력

    
합 · 차(aₓ ± bₓ , a_y ± b_y)벡터 — 이동, 방향 구하기

    
스칼라배(k·aₓ , k·a_y)벡터 — 속도 조절, 반전

    
내적aₓbₓ + a_yb_y = |a||b|cosθ스칼라 — 각도, 수직 판정, 투영

    
외적(2D)aₓb_y − a_ybₓ = |a||b|sinθ스칼라 — 넓이, 좌우 판정(CCW)

    
단위벡터â = a / |a|벡터 — 방향만 필요할 때

    
방향각θ = atan2(a_y, aₓ)스칼라 — 회전, 조준
