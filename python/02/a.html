파이썬 반복문 핵심 패턴 20제 - 정답과 해설

교사용 정답 코드와 핵심 패턴 해설

패턴 01 · for + range

1부터 N까지 출력하기

정수 N을 입력받아 1부터 N까지의 정수를 한 줄에 하나씩 출력하세요.

정답 코드
n = int(input())
for i in range(1, n + 1):
    print(i)
출력 예제
1
2
3
4
5
해설
range(1, n + 1)은 1부터 n까지 값을 차례로 만듭니다. 끝값은 포함되지 않으므로 n+1을 사용합니다.
패턴 02 · 감소 반복

N부터 1까지 거꾸로 출력하기

정수 N을 입력받아 N부터 1까지 거꾸로 출력하세요.

정답 코드
n = int(input())
for i in range(n, 0, -1):
    print(i)
출력 예제
5
4
3
2
1
해설
range(n, 0, -1)은 n부터 1까지 1씩 감소합니다.
패턴 03 · 누적합

1부터 N까지의 합

정수 N을 입력받아 1부터 N까지 모든 정수의 합을 출력하세요.

정답 코드
n = int(input())
total = 0
for i in range(1, n + 1):
    total += i
print(total)
출력 예제
15
해설
반복하면서 값을 total에 계속 더하는 누적합 패턴입니다.
패턴 04 · 반복 + 조건

1부터 N까지 짝수의 합

정수 N을 입력받아 1부터 N까지의 정수 중 짝수만 더한 값을 출력하세요.

정답 코드
n = int(input())
total = 0
for i in range(1, n + 1):
    if i % 2 == 0:
        total += i
print(total)
출력 예제
30
해설
반복문 안에서 조건문으로 짝수를 골라 누적합니다.
패턴 05 · 배수 판정

N의 배수 출력하기

두 정수 N, M을 입력받아 1부터 M까지의 수 중 N의 배수를 모두 출력하세요.

정답 코드
n, m = map(int, input().split())
for i in range(1, m + 1):
    if i % n == 0:
        print(i, end=" ")
출력 예제
3 6 9 12 15
해설
i % n == 0이면 i는 n의 배수입니다.
패턴 06 · 고정 횟수 반복

구구단 한 단 출력하기

정수 N을 입력받아 N단의 구구단을 1부터 9까지 출력하세요.

정답 코드
n = int(input())
for i in range(1, 10):
    print(n, "x", i, "=", n * i)
출력 예제
3 x 1 = 3
...
3 x 9 = 27
해설
반복 횟수가 정해진 대표적인 for문 사용 예입니다.
패턴 07 · 리스트 순회

숫자 N개 입력받아 합 구하기

첫 줄에 N, 다음 줄에 N개의 정수를 입력받아 합을 출력하세요.

정답 코드
n = int(input())
nums = list(map(int, input().split()))
total = 0
for x in nums:
    total += x
print(total)
출력 예제
150
해설
리스트의 값을 직접 하나씩 꺼내는 for x in nums 패턴입니다.
패턴 08 · 카운팅

양수의 개수 세기

첫 줄에 N, 다음 줄에 N개의 정수를 입력받아 양수의 개수를 출력하세요.

정답 코드
n = int(input())
nums = list(map(int, input().split()))
count = 0
for x in nums:
    if x > 0:
        count += 1
print(count)
출력 예제
3
해설
조건을 만족할 때마다 count를 증가시키는 카운팅 패턴입니다.
패턴 09 · 최댓값 갱신

가장 큰 수 찾기

N개의 정수 중 가장 큰 값을 출력하세요. 단, max()는 사용하지 않습니다.

정답 코드
n = int(input())
nums = list(map(int, input().split()))
maximum = nums[0]
for x in nums:
    if x > maximum:
        maximum = x
print(maximum)
출력 예제
13
해설
첫 값을 후보로 두고 더 큰 값이 나오면 갱신합니다.

패턴 11 · while 기본

while문으로 1부터 N까지 출력하기

정수 N을 입력받아 while문으로 1부터 N까지 출력하세요.

정답 코드
n = int(input())
i = 1

    print(i, end=" ")
    i += 1
출력 예제
1 2 3 4
해설
while문은 시작값, 조건, 변화식이 중요합니다.
패턴 12 · 무한 반복 + break

0이 입력될 때까지 합 구하기

정수를 계속 입력받다가 0이 입력되면 종료하고 합을 출력하세요.

정답 코드
total = 0
while True:
    n = int(input())
    if n == 0:
        break
    total += n
print(total)
출력 예제
16
해설
반복 횟수를 모를 때 while True와 break를 자주 사용합니다.
패턴 13 · continue

1부터 N까지 3의 배수 제외하기

정수 N을 입력받아 1부터 N까지 출력하되 3의 배수는 제외하세요.

정답 코드
n = int(input())
for i in range(1, n + 1):
    if i % 3 == 0:
        continue
    print(i, end=" ")
출력 예제
1 2 4 5 7 8 10
해설
continue는 현재 반복을 건너뛰고 다음 반복으로 이동합니다.

패턴 17 · 자리수 처리

각 자리수의 합

양의 정수 N을 입력받아 각 자리 숫자의 합을 while문으로 구하세요.

정답 코드
n = int(input())
total = 0
while n > 0:
    total += n % 10
    n //= 10
print(total)
출력 예제
18
해설
% 10으로 마지막 자리, // 10으로 마지막 자리를 제거합니다.
패턴 18 · 2중 for문

구구단 전체 출력하기

2단부터 9단까지 구구단을 모두 출력하세요.

정답 코드
for dan in range(2, 10):
    for i in range(1, 10):
        print(dan, "x", i, "=", dan * i)
    print()
출력 예제
2 x 1 = 2
...
9 x 9 = 81
해설
바깥 반복문은 단, 안쪽 반복문은 곱하는 수를 담당합니다.
패턴 19 · 행·열 중첩

별표 직사각형 출력하기

두 정수 N, M을 입력받아 세로 N줄, 가로 M개의 별표 직사각형을 출력하세요.

정답 코드
n, m = map(int, input().split())
for i in range(n):
    for j in range(m):
        print("*", end="")
    print()
출력 예제
*****
*****
*****
해설
바깥 반복은 행, 안쪽 반복은 열을 담당합니다.
패턴 20 · 가변 중첩 반복

계단 모양 별 찍기

정수 N을 입력받아 첫 줄 1개, 두 번째 줄 2개, ... N번째 줄 N개의 별을 출력하세요.

정답 코드
n = int(input())
for i in range(1, n + 1):
    for j in range(i):
        print("*", end="")
    print()
출력 예제
*
**
***
****
*****
해설
안쪽 반복 횟수가 현재 줄 번호 i에 따라 달라집니다.
