문제 01 · append()

리스트 끝에 값 추가하기

빈 리스트를 만든 뒤 정수 5개를 입력받아 차례대로 append()로 추가하고 최종 리스트를 출력하세요.

정답 코드
a = []

for _ in range(5):
    x = int(input())
    a.append(x)

print(a)
해설
append(x)는 리스트의 맨 뒤에 값 x를 하나 추가합니다. 입력값을 차례로 저장할 때 가장 많이 사용하는 리스트 메서드입니다.
입출력 확인
입력
10
20
30
40
50

출력
[10, 20, 30, 40, 50]

정수 리스트와 위치 K, 값 X가 주어질 때 insert()를 사용해 K번 인덱스에 X를 삽입하고 결과를 출력하세요.

정답 코드

a.insert(k, x)

문제 19 · append() + pop()

리스트를 스택처럼 사용하기

정답 코드
n = int(input())
stack = []

for _ in range(n):
    cmd = input().split()

    if cmd[0] == "push":
        stack.append(int(cmd[1]))
    else:
        print(stack.pop())
해설
append()는 스택의 push, pop()은 스택의 pop 역할을 합니다. 파이썬 리스트로 스택을 구현하는 가장 대표적인 패턴입니다.

입력
6

push 20
pop

pop
pop

출력
20
30

문제 20 · append() + insert() + remove() + pop()

간단한 할 일 목록 관리

초기에는 빈 리스트입니다. add X는 끝에 추가, first X는 맨 앞에 삽입, done X는 해당 값을 삭제, last는 마지막 값을 제거합니다. 모든 명령 처리 후 리스트를 출력하세요.

정답 코드
n = int(input())
todo = []

for _ in range(n):
    cmd = input().split()

    if cmd[0] == "add":
        todo.append(cmd[1])
    elif cmd[0] == "first":
        todo.insert(0, cmd[1])
    elif cmd[0] == "done":
        if cmd[1] in todo:
            todo.remove(cmd[1])
    elif cmd[0] == "last":
        if todo:
            todo.pop()

print(todo)
해설
여러 리스트 메서드를 실제 관리 프로그램처럼 함께 사용하는 종합 패턴입니다. 메서드 각각의 역할과 사용 상황을 익힐 수 있습니다.
입출력 확인
입력
6
add study
add coding
first breakfast
done study
add exercise
last

출력
['breakfast', 'coding']
