× CCW 완전정복 — 계산기하의 심장

외적 공식이 어디서 왔는지부터, 부호가 가진 의미, C 구현의 함정, 그리고 CCW 하나로 푸는 7가지 문제까지.

1-1공식부터 보기 — 그런데 이게 왜 방향을 알려줄까?

CCW의 공식은 이렇습니다. 대부분의 학생이 이걸 그냥 외웁니다. 하지만 어디서 왔는지 알면 절대 안 헷갈립니다.

cross(A, B, C) = (xB−xA)(yC−yA) − (yB−yA)(xC−xA)

먼저 A를 원점으로 옮겨서 두 개의 벡터로 바꿔 봅시다. 이게 첫 번째 열쇠입니다.

u→ = B − A = (ux, uy)     v→ = C − A = (vx, vy)
cross = ux·vy − uy·vx

공식이 훨씬 단순해졌습니다. 이제 "두 벡터의 외적"이라는 하나의 개념만 이해하면 됩니다. 세 점이든 뭐든, 결국 벡터 두 개의 외적입니다.

1-2의미 ①: 외적은 평행사변형의 넓이다 (부호 있는 넓이)

두 벡터 u, v가 만드는 평행사변형의 넓이가 바로 |cross| 입니다. 아래에서 두 벡터를 끌어 확인해 보세요.

|cross| = 평행사변형 넓이 = |u| · |v| · sin θ   // θ는 두 벡터 사이 각

여기서 sin θ가 핵심입니다. θ가 0°~180°면 sin θ > 0(양수), 180°~360°면 sin θ < 0(음수). 즉 v가 u보다 반시계 쪽에 있으면 양수가 됩니다. 이것이 부호가 방향을 알려주는 이유입니다.

▶ 벡터 끝점 B, C를 끌어 보세요. 각도가 180°를 넘어가는 순간 색과 부호가 바뀝니다.

기억 포인트 — 삼각형 넓이가 왜 |cross|/2 인지도 여기서 나옵니다. 평행사변형의 절반이 삼각형이니까요. 넓이·방향·각도가 전부 한 식에 들어 있습니다.

1-3의미 ②: 외적은 2×2 행렬식이다

같은 식을 행렬로 쓰면 이렇게 됩니다. 고등학교에서 배울 행렬식(determinant)과 정확히 같은 것입니다.

cross = det | ux   uy
vx   vy | = uxvy − uyvx

그래서 외적이 0이라는 것은 "두 벡터가 평행하다 = 세 점이 한 직선 위"라는 뜻이 됩니다. 행렬식이 0이면 두 벡터가 같은 방향(또는 반대 방향)을 향해 넓이가 찌그러진 것이니까요.

대각선 곱셈으로 외우기

ux     uy
   ↘  ↙
vx     vy    →   (↘ 곱) − (↙ 곱) = uxvy − uyvx
순서를 바꾸면? — cross(A,B,C) = −cross(A,C,B) 입니다. 두 벡터의 순서를 바꾸면 부호가 뒤집힙니다. 방향을 재는 도구이니 당연한 성질이며, "어느 점이 기준인지"를 항상 확인해야 하는 이유입니다.

2-2인터랙티브: CCW 판정기 (계산 과정 전개)

▶ A, B, C를 끌어 보세요. 벡터 성분부터 최종 부호까지 계산 과정이 단계별로 전개됩니다.

2-3회전 실험 — C를 원 위로 한 바퀴 돌리기

C를 A 주위로 360° 회전시키면 cross 값이 어떻게 변할까요? 사인 곡선을 그리며 두 번 0을 지나갑니다. 그 0이 되는 두 지점이 바로 C가 직선 AB 위에 놓이는 순간입니다.

이 그래프가 말해주는 것 — cross는 단순한 참/거짓이 아니라 연속적인 양입니다. 0에 가까울수록 세 점이 일직선에 가깝고, 절댓값이 클수록 넓게 벌어져 있습니다. 이 성질이 볼록 껍질에서 "가장 바깥쪽 점"을 고를 때 그대로 쓰입니다.

3-1단계별 구현 — 틀리지 않는 CCW 함수 만들기

STEP 1. 점을 구조체로 정의한다
Cstep1.c
typedef struct {
    long long x, y;      // int 아님! 이유는 5번 탭에서
} P;

P a = {0, 0}, b = {4, 0}, c = {2, 3};

구조체를 쓰면 함수에 점을 통째로 넘길 수 있어 코드가 짧아지고 실수가 줄어듭니다. 배열 x[], y[] 두 개로 관리하면 인덱스를 헷갈리기 쉽습니다.

STEP 2. 외적 값 자체를 반환하는 함수
Cstep2.c — 넓이 계산에 사용
long long cross(P a, P b, P c) {
    return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
}
// cross({0,0},{4,0},{2,3}) = 4*3 - 0*2 = 12

이 함수는 값이 필요할 때 씁니다 — 삼각형 넓이(|cross|/2), 신발끈 공식, 크기 비교.

STEP 3. 부호만 반환하는 함수
Cstep3.c — 판정에 사용
int ccw(P a, P b, P c) {
    long long v = cross(a, b, c);
    if (v > 0) return  1;   // 반시계
    if (v < 0) return -1;   // 시계
    return 0;                  // 공선
}

// 한 줄 버전 (같은 동작)
int sgn(long long v) { return (v > 0) - (v < 0); }

왜 부호만 따로 만드나? 판정 문제에서 곱셈을 할 때 원본 값끼리 곱하면 오버플로가 납니다. 예를 들어 선분 교차 판정의 ccw(a,b,c) * ccw(a,b,d) 에서 값이 각각 1018이면 곱은 1036 — 절대 불가능합니다. 부호(−1, 0, 1)로 줄인 다음 곱해야 안전합니다.

STEP 4. 전체 뼈대 — 그대로 외우는 템플릿
Cccw_template.c — 시험장 복사용
#include <stdio.h>
#include <stdlib.h>

typedef struct { long long x, y; } P;

long long cross(P a, P b, P c) {
    return (b.x-a.x)*(c.y-a.y) - (b.y-a.y)*(c.x-a.x);
}
int ccw(P a, P b, P c) {
    long long v = cross(a, b, c);
    return (v > 0) - (v < 0);
}

int main(void) {
    P p[3];
    for (int i = 0; i < 3; i++)
        scanf("%lld %lld", &p[i].x, &p[i].y);   // %lld 주의!
    printf("%d\n", ccw(p[0], p[1], p[2]));
    return 0;
}
scanf 서식 문자 실수 — long long은 %lld, 출력도 %lld입니다. %d를 쓰면 값이 깨져서 원인을 못 찾고 헤매게 됩니다. 이것이 계산기하 디버깅에서 가장 흔한 시간 낭비입니다.

4CCW 하나로 푸는 7가지 문제

아래 7가지는 전부 같은 cross 함수 하나만 씁니다. 이것이 CCW를 먼저 완벽히 익혀야 하는 이유입니다.

#문제CCW 사용법
1점이 선분의 어느 쪽인가ccw(a,b,p) 의 부호
2세 점이 일직선인가cross == 0
3삼각형 넓이|cross| / 2
4다각형 넓이 · 방향신발끈 = Σ cross, 부호가 방향
5다각형이 볼록인가연속 3점의 ccw 부호가 모두 같은가
6점이 볼록다각형 내부인가모든 변에 대해 ccw 부호가 같은가
7각도 순 정렬(극각 정렬)비교 함수에서 cross 부호로 대소 결정

4-1응용 ①②③: 위치 · 공선 · 넓이

▶ 점 P를 끌어 선분 AB 기준 위치를 확인하세요. 세 값이 동시에 갱신됩니다.

Capply123.c
int side = ccw(a, b, p);          // ① 왼쪽(1)/오른쪽(-1)/위(0)
int collinear = (cross(a,b,p) == 0);   // ② 공선 판정
long long area2 = llabs(cross(a,b,p)); // ③ 넓이의 2배 (정수 유지!)
printf("%lld.%d\n", area2/2, (int)(area2%2)*5);  // 소수 첫째 자리까지

4-2응용 ④⑤: 다각형의 방향과 볼록성

다각형의 각 꼭짓점에서 연속한 세 점의 ccw 부호를 보면, 부호가 전부 같으면 볼록, 하나라도 다르면 오목입니다. 그 부호 자체가 다각형의 진행 방향이기도 합니다.

▶ 꼭짓점을 끌어 오목하게 만들어 보세요. 부호가 다른 꼭짓점이 빨갛게 표시됩니다.

Cconvex_check.c
int isConvex(P *p, int n) {
    int s = 0;
    for (int i = 0; i < n; i++) {
        int v = ccw(p[i], p[(i+1)%n], p[(i+2)%n]);
        if (v == 0) continue;          // 일직선 꼭짓점은 무시
        if (s == 0) s = v;              // 첫 부호 기억
        else if (s != v) return 0;      // 부호 다름 → 오목
    }
    return 1;
}
// %n 으로 인덱스를 순환시키는 것이 핵심 (마지막→첫 꼭짓점 연결)

4-3응용 ⑥: 점이 볼록다각형 내부인가

볼록다각형을 반시계 방향으로 돌면서 각 변 (Pi, Pi+1)에 대해 ccw(Pi, Pi+1, q)를 구합니다. 전부 같은 부호면 내부, 하나라도 반대면 외부, 0이 섞이면 경계입니다.

▶ 노란 점 q를 끌어 안팎으로 옮겨 보세요. 각 변의 판정 결과가 실시간으로 표시됩니다.

왜 볼록다각형만? — 오목다각형에서는 이 방법이 통하지 않습니다. 오목 다각형은 광선 쏘기(ray casting)로 교차 횟수의 홀짝을 세야 합니다. 문제에서 "볼록"이라는 단어가 보이면 이 O(n) 판정을 바로 떠올리세요.

4-4응용 ⑦: 극각 정렬 (angular sort)

여러 점을 원점에서 본 각도 순으로 정렬합니다. atan2를 쓰면 실수 오차가 생기므로, CCW로 비교 함수를 만듭니다.

[정렬 애니메이션]을 눌러 각도 순으로 정렬되는 과정을 확인하세요.
Cpolar_sort.c — qsort 비교 함수
// 위/아래 반평면을 먼저 나눈다 (0°~180° 가 앞)
int half(P p) {
    return (p.y > 0 || (p.y == 0 && p.x > 0)) ? 0 : 1;
}
int cmp(const void *A, const void *B) {
    P a = *(P*)A, b = *(P*)B;
    if (half(a) != half(b)) return half(a) - half(b);
    long long c = a.x*b.y - a.y*b.x;      // 원점 기준 외적
    if (c > 0) return -1;   // a가 b보다 시계 반대쪽 = 앞
    if (c < 0) return  1;
    // 각도가 같으면 가까운 점 먼저
    return (a.x*a.x + a.y*a.y < b.x*b.x + b.y*b.y) ? -1 : 1;
}
half() 가 왜 필요한가 — 외적만으로 비교하면 "a가 b보다 앞"이면서 동시에 "b가 a보다 앞"인 모순이 생겨 정렬이 깨집니다(각도 차가 180°를 넘는 경우). 반평면으로 먼저 나눠야 순서가 일관됩니다. 이것이 극각 정렬의 가장 유명한 함정입니다.

가장 치명적

아래는 실제로 gcc로 컴파일해 실행한 결과입니다. 같은 세 점인데 자료형만 다릅니다.

Coverflow_demo.c — A(0,0) B(60000,0) C(0,50000)
int bad  = (bx-ax)*(cy-ay) - (by-ay)*(cx-ax);

// ll   cross =  3000000000  -> CCW(반시계)   ← 정답
참값 60000 × 50000 = 3,000,000,000
int 최댓값             = 2,147,483,647

안전 규칙 — 계산기하에서는 고민하지 말고 처음부터 long long을 쓰세요. 좌표가 작아도 손해가 없습니다. 그리고 int 변수끼리 곱할 때는 반드시 (long long) 캐스팅을 곱하기 전에 붙여야 합니다.

long long v1 = (long long)(dx * dy);    // 틀림: int로 곱한 뒤 변환 → 이미 늦음
long long v2 = (long long)dx * dy;      // 맞음: 곱하기 전에 변환

5-22번 함정: 부호 곱셈 전에 줄이지 않기

C위험한 코드 ⚠️
long long v1 = cross(a,b,c);
long long v2 = cross(a,b,d);
if (v1 * v2 <= 0) ...   // 10^18 × 10^18 = 폭발
C안전한 코드 ✅
int s1 = ccw(a,b,c);   // -1, 0, 1 로 축소
int s2 = ccw(a,b,d);
if (s1 * s2 <= 0) ...   // 최대 1 × 1

부호 함수 ccw()를 값 함수 cross()와 따로 만들어 두는 진짜 이유가 여기 있습니다.

5-33번 함정: 실수(double)를 쓰는 순간 무너진다

"어차피 부호만 보는데 double이면 어때?"라고 생각하기 쉽습니다. 아래는 반례입니다.

A(0, 0), B(3, 1), C(3000000, 1000000)  →  정확히 공선 (cross = 0)
정수 계산: 0  |  double 계산: −1.19e−7 같은 미세한 쓰레기 값

double은 유효숫자가 약 15~16자리라 큰 좌표에서 "정확히 0"을 만들어내지 못합니다. 공선인데 공선이 아니라고 판정하면 볼록 껍질이 깨지고 교차 판정이 틀립니다.

결론 — 문제의 좌표가 정수로 주어지면 끝까지 정수로만 계산하세요. 나눗셈이 필요하면 최대한 미루고, 넓이는 "2배 값"을 정수로 들고 다니다가 출력할 때만 처리합니다.

5-44번 함정: cross == 0 을 잊는다

시험 문제의 반례는 대부분 "딱 걸치는 경우"에서 나옵니다.

상황cross 값놓치면 생기는 일
세 점이 일직선0삼각형 넓이 0 → 0으로 나누기 오류
